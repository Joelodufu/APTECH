## 🧩 **3.1 Introduction to NIO (New I/O)**

### 📖 What is NIO?

**NIO** stands for **New Input/Output**, introduced in **Java 7** under the package `java.nio.file`.

It provides a **more flexible, faster, and powerful** way to handle files and directories than the traditional `java.io` classes.

---

### 🧱 **Why NIO?**

| Feature             | java.io       | java.nio.file                       |
| ------------------- | ------------- | ----------------------------------- |
| File Representation | `File` object | `Path` interface                    |
| Performance         | Slower        | Faster (buffered and channel-based) |
| File Operations     | Limited       | Rich and easy-to-use utilities      |
| Exception Handling  | Manual        | Streamlined                         |
| Symbolic Links      | No support    | Supported                           |
| Atomic Operations   | No            | Yes                                 |

## 🧩 **3.2 Understanding `Path` and `Paths`**

### 🔹 **Path**

- Represents the **location** of a file or directory.
- Works across operating systems.

### 🔹 **Paths**

- A utility class used to **create Path objects**.

---

### 💻 **Example 1: Creating a Path**

```java
import java.nio.file.Path;
import java.nio.file.Paths;

public class PathExample {
    public static void main(String[] args) {
        Path path = Paths.get("C:/Users/Public/test.txt");
        System.out.println("File Name: " + path.getFileName());
        System.out.println("Parent: " + path.getParent());
        System.out.println("Absolute Path: " + path.toAbsolutePath());
        System.out.println("Root: " + path.getRoot());
    }
}
```

**Explanation:**

- `Paths.get()` creates a Path instance.
- You can extract details like file name, parent directory, root, etc.

---

### 💡 **Tip:**

You can also use relative paths:

```java
Path relativePath = Paths.get("data/info.txt");
```

## 🧱 **3.3 The `Files` Class**

The `Files` class contains **static utility methods** for file manipulation such as creating, copying, moving, reading, and deleting.

---

### 💻 **Example 2: Creating a New File**

```java
import java.nio.file.*;

public class CreateFileExample {
    public static void main(String[] args) {
        Path filePath = Paths.get("newfile.txt");
        try {
            Files.createFile(filePath);
            System.out.println("File created successfully.");
        } catch (FileAlreadyExistsException e) {
            System.out.println("File already exists!");
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

**Explanation:**

- `Files.createFile()` creates a new file.
- Throws `FileAlreadyExistsException` if it already exists.

---

### 💻 **Example 3: Creating a Directory**

```java
import java.nio.file.*;

public class CreateDirectoryExample {
    public static void main(String[] args) {
        Path dirPath = Paths.get("Documents/JavaFiles");
        try {
            Files.createDirectories(dirPath);
            System.out.println("Directories created successfully!");
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

**Note:**

- `createDirectory()` → creates one directory.
- `createDirectories()` → creates parent directories if they don’t exist.

## 🧩 **3.4 Checking File Properties**

Use methods from `Files` to check file details:

**Example 4: Checking File Information**

```java
import java.nio.file.*;

public class FileInfoExample {
    public static void main(String[] args) {
        Path file = Paths.get("newfile.txt");

        System.out.println("Exists: " + Files.exists(file));
        System.out.println("Readable: " + Files.isReadable(file));
        System.out.println("Writable: " + Files.isWritable(file));
        System.out.println("Executable: " + Files.isExecutable(file));
        System.out.println("Is Directory: " + Files.isDirectory(file));
    }
}
```

## ⚙️ **3.5 Copying, Moving, and Deleting Files**

### 💻 **Example 5: Copying Files**

```java
import java.nio.file.*;

public class CopyFileExample {
    public static void main(String[] args) {
        Path source = Paths.get("data.txt");
        Path destination = Paths.get("backup/data_copy.txt");

        try {
            Files.copy(source, destination, StandardCopyOption.REPLACE_EXISTING);
            System.out.println("File copied successfully.");
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

---

### 💻 **Example 6: Moving Files**

```java
import java.nio.file.*;

public class MoveFileExample {
    public static void main(String[] args) {
        Path source = Paths.get("data.txt");
        Path target = Paths.get("archive/data.txt");

        try {
            Files.move(source, target, StandardCopyOption.REPLACE_EXISTING);
            System.out.println("File moved successfully.");
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

---

### 💻 **Example 7: Deleting Files**

## 📖 **3.6 Reading and Writing Files with NIO**

Instead of using `FileReader` and `FileWriter`, you can use the `Files` class for quick operations.

---

### 💻 **Example 8: Writing to a File**

```java
import java.nio.file.*;
import java.io.IOException;
import java.util.*;

public class NIOWriteExample {
    public static void main(String[] args) {
        Path file = Paths.get("notes.txt");
        List<String> lines = Arrays.asList("Hello, Java NIO!", "It’s fast and efficient.");
        try {
            Files.write(file, lines);
            System.out.println("File written successfully.");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

---

### 💻 **Example 9: Reading a File**

```java
import java.nio.file.*;
import java.io.IOException;
import java.util.List;

public class NIOReadExample {
    public static void main(String[] args) {
        Path file = Paths.get("notes.txt");
        try {
            List<String> lines = Files.readAllLines(file);
            for (String line : lines) {
                System.out.println(line);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

---

### 💻 **Example 10: Reading Large Files Using Stream**

```java
import java.nio.file.*;
import java.util.stream.Stream;

public class StreamReadExample {
    public static void main(String[] args) {
        Path file = Paths.get("notes.txt");
        try (Stream<String> lines = Files.lines(file)) {
            lines.forEach(System.out::println);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

**Explanation:**

- `Files.lines()` returns a Stream of file lines.
- Efficient for large files as it reads lazily (line by line).

## 🧾 **3.7 Getting File Metadata**

Use `Files.getAttribute()` or helper methods to get file size, creation time, etc.

**Example 11: File Metadata**

```java
import java.nio.file.*;
import java.nio.file.attribute.*;
import java.io.IOException;

public class FileMetadataExample {
    public static void main(String[] args) {
        Path path = Paths.get("notes.txt");
        try {
            BasicFileAttributes attr = Files.readAttributes(path, BasicFileAttributes.class);
            System.out.println("Creation Time: " + attr.creationTime());
            System.out.println("Last Modified: " + attr.lastModifiedTime());
            System.out.println("Size: " + attr.size() + " bytes");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```
