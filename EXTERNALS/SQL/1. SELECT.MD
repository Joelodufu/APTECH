# 📘 SQL CLASS NOTE – MODULE 1: 'SELECT'

---

## 1. Introduction

The **'SELECT' statement** is the **foundation of SQL**.
It allows you to **ask questions** (queries) from your database and **retrieve specific information**.

- Without 'SELECT', a database is like a locked library: it has books (data), but you can’t read them.
- With 'SELECT', you’re asking:

  > “Show me this book, this page, or just these sentences.”

---

## 2. Syntax

```sql
SELECT column1, column2, ...
FROM table_name;
```

- 'SELECT' → tells the database _what you want to see_.
- 'FROM' → tells the database _where (which table)_ to get it from.
- '\*' → means “all columns”.

---

## 3. Practical Examples with 'SchoolDB'

### Example 1: Select all student data

```sql
SELECT \*
FROM Students;
```

- This retrieves **all columns** (ID, Name, Age, Gender, GradeLevel).
- ⚠️ Use carefully — if a table has thousands of columns/rows, this can be slow.

---

### Example 2: Select specific columns

```sql
SELECT FirstName, LastName, Age
FROM Students;
```

- This retrieves only **FirstName, LastName, and Age**.
- Useful when you don’t need everything.

---

### Example 3: Select data from another table

```sql
SELECT CourseName, Teacher
FROM Courses;
```

- Displays **all courses** and their **teachers**.

---

### Example 4: Select with aliases (renaming)

```sql
SELECT FirstName AS "First Name", LastName AS "Last Name"
FROM Students;
```

- 'AS' renames columns in the result set.
- Great for making reports more **readable**.

---

### Example 5: Select with calculations

```sql
SELECT FirstName, Age, Age + 1 AS "Age Next Year"
FROM Students;
```

- You can perform **arithmetic operations** on numeric fields.
- Here we calculate how old each student will be next year.

---

### Example 6: Select distinct values

```sql
SELECT DISTINCT GradeLevel
FROM Students;
```

- Removes duplicates, showing each grade **only once**.

---

### Example 7: Select with string concatenation

```sql
SELECT CONCAT(FirstName, ' ', LastName) AS FullName
FROM Students;
```

- Combines 'FirstName' + 'LastName' into one column **FullName**.

---

### Example 8: Select with ordering (preview for later module)

```sql
SELECT FirstName, Age
FROM Students
ORDER BY Age DESC;
```

- Retrieves names and ages, sorted **from oldest to youngest**.

---

## 4. Why Use 'SELECT'? (Real-Life Use Cases)

- **Schools** → Generate student lists, attendance reports.
- **Banks** → View customer transactions.
- **Hospitals** → Display patient records.
- **E-commerce** → Show products, prices, and categories.
- **Social Media** → Retrieve posts, likes, and user data.

---

## 5. Key Notes to Remember

- 'SELECT \*' is good for quick checks, but avoid in production (too much unnecessary data).
- Always select only the **columns you need**.
- Use **aliases** ('AS') to make output readable.
- Combine with functions ('COUNT', 'SUM', 'AVG', etc.) to get deeper insights (covered in later modules).

# ✅ Solutions to Module 1 Classwork

### 1. Show all student **FirstNames** and **LastNames** only.

```sql
SELECT FirstName, LastName
FROM Students;
```

---

### 2. Show all courses with their **CourseCode**.

```sql
SELECT CourseName, CourseCode
FROM Courses;
```

---

### 3. Create a column 'FullName' that combines First and Last name.

```sql
SELECT CONCAT(FirstName, ' ', LastName) AS FullName
FROM Students;
```

---

### 4. Show all distinct 'GradeLevel' values.

```sql
SELECT DISTINCT GradeLevel
FROM Students;
```

---

### 5. Show each student’s 'FirstName', 'Age', and their 'Age in Months' ('Age \* 12').

```sql
SELECT FirstName, Age, (Age \* 12) AS AgeInMonths
FROM Students;
```

---

### 6. Select all male students and rename the column 'Gender' to 'Sex'.

```sql
SELECT FirstName, LastName, Gender AS Sex
FROM Students
WHERE Gender = 'Male';
```

---

### 7. Display all students but order them by **FirstName alphabetically**.

```sql
SELECT FirstName, LastName, Age, GradeLevel
FROM Students
ORDER BY FirstName ASC;
```

# 💡 Challenge Question Solution

👉 List all students in **Grade 10** and display:

- Full Name (First + Last)
- Age
- Grade Level (renamed as 'Class')

```sql
SELECT CONCAT(FirstName, ' ', LastName) AS FullName,
Age,
GradeLevel AS Class
FROM Students
WHERE GradeLevel = 'Grade 10';
```
