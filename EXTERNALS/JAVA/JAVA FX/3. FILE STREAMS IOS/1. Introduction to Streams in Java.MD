# 🧑‍💻 **Session 1: Introduction to Streams in Java**

---

## 🎯 **Lesson Objective**

By the end of this session, students should be able to:

1. Explain what a stream is and why Java uses it.
2. Differentiate between byte streams and character streams.
3. Understand how data flows from a source to a destination.
4. Write basic input and output operations using Java Streams.

---

## 🧩 **1. What is a Stream?**

A **Stream** in Java represents a **continuous flow of data** — either coming _into_ a program or going _out_ of it.
It acts as a **pipeline** connecting the program to data sources like files, networks, memory, or the keyboard.

📖 **Think of it like water flowing through a pipe:**

- The **source** (file, network, or user input) is where the data comes from.
- The **stream** is the pipe through which the data flows.
- The **destination** is where data is going (a file, a printer, or console output).

---

## 🧠 **2. Why Do We Need Streams?**

Before Java introduced streams, handling data from different sources (like files, keyboard input, or network connections) required writing separate logic for each one.
Streams solved this by **standardizing input and output operations** — everything became an **InputStream** or **OutputStream**.

So now, whether we are reading from:

- a **file**
- a **keyboard**
- or a **network socket**

…it’s all handled using the **same concept** — streams!

---

## 💡 **3. Input and Output Streams**

In Java, the `java.io` package defines two main abstract classes for handling streams:

| Type          | Class          | Purpose                         |
| ------------- | -------------- | ------------------------------- |
| Input Stream  | `InputStream`  | Used to **read** data (input)   |
| Output Stream | `OutputStream` | Used to **write** data (output) |

👉 These two form the base of all stream-related classes.

---

## 🧾 **4. Stream Data Flow Concept**

Below is a simple mental picture:

```
Input Stream:         [ Keyboard / File / Network ] ---> [ Java Program ]
Output Stream:        [ Java Program ] ---> [ File / Screen / Network ]
```

Java handles data as **a sequence of bytes or characters**, flowing through these streams.

---

## 🪣 **5. Byte Streams vs Character Streams**

| Stream Type          | Description                                   | Example Classes                                                      | Typical Use                              |
| -------------------- | --------------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------- |
| **Byte Stream**      | Handles binary data (8-bit bytes)             | `InputStream`, `OutputStream`, `FileInputStream`, `FileOutputStream` | For images, audio, or other binary files |
| **Character Stream** | Handles text data (16-bit Unicode characters) | `Reader`, `Writer`, `FileReader`, `FileWriter`                       | For text files and readable content      |

---

## 🧪 **6. Simple Example — Reading Input and Writing Output**

Let’s do a very basic demonstration.

### Example 1: Using `System.in` and `System.out`

```java
import java.io.IOException;

public class SimpleStreamExample {
    public static void main(String[] args) throws IOException {
        System.out.println("Enter a character: ");

        // Reading a single byte from keyboard
        int input = System.in.read();

        System.out.println("You entered: " + (char) input);
    }
}
```

🧠 **Explanation:**

- `System.in` → standard input stream (reads bytes from keyboard)
- `System.out` → standard output stream (prints to console)
- `.read()` → reads **one byte** at a time

⚙️ **Output Example:**

```
Enter a character:
A
You entered: A
```

---

### Example 2: Reading a Line and Converting It to Uppercase

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class StreamTextExample {
    public static void main(String[] args) throws IOException {
        BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));

        System.out.print("Enter your sentence: ");
        String input = reader.readLine();

        System.out.println("Uppercase version: " + input.toUpperCase());
    }
}
```

🧠 **Explanation:**

- `InputStreamReader` converts bytes into characters.
- `BufferedReader` helps read text efficiently, line by line.

---

## 🧮 **7. Anatomy of a Basic Stream Operation**

Every stream operation follows this flow:

1. **Open** the stream
2. **Perform** read/write operations
3. **Close** the stream to release resources

Example:

```java
FileInputStream fis = new FileInputStream("data.txt");  // Step 1
int data = fis.read();                                   // Step 2
fis.close();                                             // Step 3
```

If you forget to close a stream, it can cause **memory leaks** or **file locks**.

---

## ⚙️ **8. Real-Life Analogy**

Imagine a **water tap system**:

| Water Flow Part | Java Equivalent                | Description       |
| --------------- | ------------------------------ | ----------------- |
| Tap             | Stream source (file, keyboard) | Provides the data |
| Pipe            | Stream object                  | Transfers data    |
| Bucket          | Destination (program, file)    | Collects data     |

So when you read or write data, you’re simply **transferring “information water”** from one container to another.

## 🧩 **9. Summary**

| Concept                    | Meaning                                                   |
| -------------------------- | --------------------------------------------------------- |
| **Stream**                 | A sequence of data flowing from a source to a destination |
| **InputStream**            | Reads data into a program                                 |
| **OutputStream**           | Sends data out of a program                               |
| **Byte Streams**           | For binary data                                           |
| **Character Streams**      | For text data                                             |
| **BufferedReader**         | Efficiently reads text                                    |
| **System.in / System.out** | Keyboard input and console output                         |

## 🧰 **12. Key Takeaways**

- Streams provide a unified model for all data input/output in Java.
- Everything that comes in or goes out of a program is a stream.
- Always **close** your streams after use.
- Java separates data into **bytes** (for binary) and **characters** (for text).
- The `java.io` package is the foundation of stream handling.
