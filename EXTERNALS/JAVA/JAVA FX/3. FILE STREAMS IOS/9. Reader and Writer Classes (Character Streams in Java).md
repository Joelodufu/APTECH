
# **Module 3: File Handling, Stream API, and Related Concepts**

## **Session 9: Character Streams — Reader and Writer Classes**

---

### **1. Introduction**

So far, we’ve worked with **byte-based streams** like `InputStream` and `OutputStream`.
They are perfect for **binary data** (e.g., images, videos, etc.), but not ideal for **text data**.

Why?
Because text data involves **characters**, and characters in Java use **Unicode encoding** (which can be more than one byte per character).

That’s where **Character Streams** come in.

Character streams automatically handle character encoding and decoding for you.

---

### **2. What Are Character Streams?**

Character Streams in Java are designed for **reading and writing characters (text)** efficiently.

They use:

* **`Reader`** → to read characters from a source.
* **`Writer`** → to write characters to a destination.

These classes work with **16-bit Unicode characters**, unlike byte streams that work with raw bytes (8 bits).

---

### **3. The Reader and Writer Hierarchy**

Here’s the inheritance structure for character streams:

```
                Reader (abstract)
                   /      \
    BufferedReader        InputStreamReader
          |                      |
      FileReader             (used for byte-to-char conversion)

                Writer (abstract)
                   /      \
    BufferedWriter        OutputStreamWriter
          |                      |
      FileWriter             (used for char-to-byte conversion)
```

---

### **4. The Reader Class**

#### **Class Declaration**

```java
public abstract class Reader implements Readable, Closeable
```

#### **Common Methods**

| **Method**              | **Description**                           |
| ----------------------- | ----------------------------------------- |
| `int read()`            | Reads a single character.                 |
| `int read(char[] cbuf)` | Reads multiple characters into an array.  |
| `void close()`          | Closes the stream.                        |
| `boolean ready()`       | Checks if the stream is ready to be read. |

---

### **5. Example: Reading a File Using FileReader**

```java
import java.io.FileReader;
import java.io.IOException;

public class FileReaderExample {
    public static void main(String[] args) {
        try (FileReader reader = new FileReader("data.txt")) {
            int ch;
            while ((ch = reader.read()) != -1) {
                System.out.print((char) ch);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

✅ The program reads the file **character by character** and prints it to the console.
✅ Using `try-with-resources` automatically closes the file.

---

### **6. Reading Multiple Characters at Once**

```java
import java.io.FileReader;
import java.io.IOException;

public class MultiCharReadExample {
    public static void main(String[] args) {
        try (FileReader reader = new FileReader("sample.txt")) {
            char[] buffer = new char[50];
            int charsRead;
            while ((charsRead = reader.read(buffer)) != -1) {
                System.out.println(new String(buffer, 0, charsRead));
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

✅ This method reads multiple characters in chunks — faster than reading one by one.

---

### **7. The Writer Class**

#### **Class Declaration**

```java
public abstract class Writer implements Appendable, Closeable, Flushable
```

#### **Common Methods**

| **Method**                | **Description**                        |
| ------------------------- | -------------------------------------- |
| `void write(int c)`       | Writes a single character.             |
| `void write(char[] cbuf)` | Writes an array of characters.         |
| `void write(String str)`  | Writes a string.                       |
| `void flush()`            | Forces data to be written immediately. |
| `void close()`            | Closes the stream.                     |

---

### **8. Example: Writing to a File Using FileWriter**

```java
import java.io.FileWriter;
import java.io.IOException;

public class FileWriterExample {
    public static void main(String[] args) {
        try (FileWriter writer = new FileWriter("output.txt")) {
            writer.write("Welcome to Swift Space Academy!");
            writer.write("\nLet's master Java File Handling.");
            System.out.println("File written successfully!");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

✅ The file will contain two lines of text written by the program.

---

### **9. Appending Data to an Existing File**

If you want to **add** new content without erasing existing data:

```java
import java.io.FileWriter;
import java.io.IOException;

public class AppendExample {
    public static void main(String[] args) {
        try (FileWriter writer = new FileWriter("output.txt", true)) {
            writer.write("\nNew line added without overwriting!");
            System.out.println("Data appended successfully!");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

✅ The second parameter `true` enables append mode.

### **10. BufferedReader and BufferedWriter**

These are **wrapper classes** that make character reading/writing **faster and more efficient** by using internal buffers.

#### **BufferedReader Example**

```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class BufferedReaderExample {
    public static void main(String[] args) {
        try (BufferedReader br = new BufferedReader(new FileReader("note.txt"))) {
            String line;
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

✅ Reads an entire line of text at once — ideal for text files.

#### **BufferedWriter Example**

```java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class BufferedWriterExample {
    public static void main(String[] args) {
        try (BufferedWriter bw = new BufferedWriter(new FileWriter("note.txt"))) {
            bw.write("Swift Space is amazing!");
            bw.newLine();
            bw.write("Buffered writing improves performance.");
            System.out.println("Writing completed!");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

---

### **11. PrintWriter Class**

`PrintWriter` provides convenient methods like `print()` and `println()` — similar to `System.out`.

```java
import java.io.PrintWriter;
import java.io.IOException;

public class PrintWriterExample {
    public static void main(String[] args) {
        try (PrintWriter pw = new PrintWriter("report.txt")) {
            pw.println("Swift Space Report");
            pw.println("=================");
            pw.println("Students enrolled: 150");
            pw.println("Modules completed: 3");
            System.out.println("Report generated!");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

✅ Automatically handles text formatting.

### **12. Comparison: Byte Streams vs. Character Streams**

| **Aspect**   | **Byte Streams**                  | **Character Streams**        |
| ------------ | --------------------------------- | ---------------------------- |
| Base Classes | InputStream / OutputStream        | Reader / Writer              |
| Data Type    | Raw bytes                         | Characters                   |
| Encoding     | Manual handling                   | Automatic (Unicode-aware)    |
| Use Case     | Binary data (images, audio, etc.) | Text data (files, documents) |

---

### **13. Real-Life Use Cases**

✅ Building text editors or log systems.
✅ Reading and writing configuration files.
✅ Saving and loading reports.
✅ Generating structured documents.

---

### **14. Common Mistakes to Avoid**

❌ Using byte streams for text — may corrupt Unicode characters.
✅ Use Reader/Writer for all **text-based** operations.

❌ Forgetting to flush or close streams — may lose data.
✅ Always close or use try-with-resources.

❌ Not buffering — leads to poor performance.
✅ Use BufferedReader and BufferedWriter for large files.
