
# **Module 3: File Handling, Stream API, and Related Concepts**

## **Session 8: OutputStream Class and Its Subclasses**

---

### **1. Introduction**

In the previous session, we studied the **InputStream** class — the foundation of reading byte data **into** a Java program.

Now, we’ll study its counterpart: **OutputStream**, which handles **sending byte data out** — usually to a file, memory, or network.

You can think of InputStream and OutputStream as **opposites**:

```
InputStream  →  Reads data into your program  
OutputStream →  Writes data out from your program
```

---

### **2. What is OutputStream?**

The **`OutputStream`** is an **abstract class** in the `java.io` package that represents a stream of bytes going **out** of a program to some destination.

Examples of destinations:

* Files (`FileOutputStream`)
* Memory buffers (`ByteArrayOutputStream`)
* Network sockets
* Pipes (for inter-thread communication)

---

### **3. Class Declaration**

```java
public abstract class OutputStream extends Object implements Closeable, Flushable
```

This shows that `OutputStream`:

* Is **abstract** (cannot be instantiated directly).
* Implements **Closeable** (so you can close it).
* Implements **Flushable** (so you can flush its data).

---

### **4. Core Methods of OutputStream**

| **Method**                               | **Description**                                     |
| ---------------------------------------- | --------------------------------------------------- |
| `void write(int b)`                      | Writes one byte to the output stream.               |
| `void write(byte[] b)`                   | Writes all bytes from the specified array.          |
| `void write(byte[] b, int off, int len)` | Writes part of an array (from `off` to `len`).      |
| `void flush()`                           | Forces any buffered data to be written immediately. |
| `void close()`                           | Closes the stream and releases system resources.    |

---

### **5. Example: Writing a File Using FileOutputStream**

```java
import java.io.FileOutputStream;
import java.io.IOException;

public class FileOutputExample {
    public static void main(String[] args) {
        String text = "Welcome to Swift Space Learning!";

        try {
            FileOutputStream fos = new FileOutputStream("output.txt");
            fos.write(text.getBytes());
            fos.close();
            System.out.println("File written successfully!");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

**Explanation:**

* `getBytes()` converts the string into bytes.
* `write()` sends those bytes into the file.
* The file `output.txt` will contain your text.

---

### **6. Writing with try-with-resources (Recommended)**

```java
import java.io.FileOutputStream;
import java.io.IOException;

public class TryWithResourceExample {
    public static void main(String[] args) {
        String message = "Java OutputStream makes file writing easy.";

        try (FileOutputStream fos = new FileOutputStream("message.txt")) {
            fos.write(message.getBytes());
            System.out.println("Message saved successfully!");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

✅ The **try-with-resources** block automatically closes the stream — no need to call `close()` manually.

---

### **7. Writing Partial Data (write(byte[], int, int))**

```java
import java.io.FileOutputStream;
import java.io.IOException;

public class PartialWriteExample {
    public static void main(String[] args) {
        byte[] data = "Swift Space Rocks the World!".getBytes();

        try (FileOutputStream fos = new FileOutputStream("partial.txt")) {
            fos.write(data, 0, 11); // Writes only "Swift Space"
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### **8. Subclasses of OutputStream**

| **Subclass**              | **Description**                                               |
| ------------------------- | ------------------------------------------------------------- |
| **FileOutputStream**      | Writes bytes to a file.                                       |
| **ByteArrayOutputStream** | Writes bytes into an internal memory buffer (byte array).     |
| **BufferedOutputStream**  | Buffers data for efficient writing.                           |
| **DataOutputStream**      | Writes Java primitive data types in binary form.              |
| **ObjectOutputStream**    | Serializes objects into an output stream.                     |
| **PipedOutputStream**     | Sends data to a connected PipedInputStream (used in threads). |

---

### **9. The FileOutputStream Class**

`FileOutputStream` is the most common OutputStream used for file writing.

**Example:**

```java
import java.io.FileOutputStream;
import java.io.IOException;

public class FileOutputStreamExample {
    public static void main(String[] args) {
        String text = "Data saved using FileOutputStream.";

        try (FileOutputStream fos = new FileOutputStream("fileoutput.txt")) {
            fos.write(text.getBytes());
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

---

### **10. The ByteArrayOutputStream Class**

This class writes data **into memory** instead of a file — it stores everything in a byte array internally.

**Example:**

```java
import java.io.ByteArrayOutputStream;
import java.io.IOException;

public class ByteArrayOutputStreamExample {
    public static void main(String[] args) throws IOException {
        ByteArrayOutputStream baos = new ByteArrayOutputStream();
        baos.write("Swift Space!".getBytes());

        String data = baos.toString();
        System.out.println("Data in memory: " + data);

        baos.close();
    }
}
```

✅ This is very useful for combining data before writing it to a file or network.

---

### **11. The BufferedOutputStream Class**

Writing directly to disk can be **slow**, so BufferedOutputStream speeds it up using a **buffer**.

```java
import java.io.BufferedOutputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class BufferedOutputStreamExample {
    public static void main(String[] args) {
        String text = "Buffered writing improves performance.";

        try (BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("buffered.txt"))) {
            bos.write(text.getBytes());
            bos.flush(); // Ensures all data is written
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

---

### **12. Writing Primitive Data (DataOutputStream)**

To store primitive data types efficiently (e.g., int, float, boolean):

```java
import java.io.DataOutputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class DataOutputStreamExample {
    public static void main(String[] args) {
        try (DataOutputStream dos = new DataOutputStream(new FileOutputStream("data.bin"))) {
            dos.writeInt(100);
            dos.writeDouble(25.75);
            dos.writeBoolean(true);
            dos.writeUTF("Swift Space");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

✅ This stores binary data — faster and more compact than writing plain text.

---

### **13. Using flush()**

When writing data, some may remain in the buffer.
`flush()` ensures all buffered data is pushed to the destination immediately.

```java
bos.write(data);
bos.flush(); // ensures immediate write
```

Always use `flush()` when working with network streams or when writing partial data frequently.

---

### **14. Real-Life Use Cases**

✅ Saving logs or reports to files.
✅ Sending data through network sockets.
✅ Writing multimedia files (images, videos).
✅ Storing binary data or serialized objects.
✅ Writing cached or combined data using buffers.

---

### **15. Common Mistakes to Avoid**

❌ Forgetting to close the stream — leads to **file corruption or resource leaks**.
✅ Always use **try-with-resources** to handle this automatically.

❌ Writing text directly to binary streams without encoding.
✅ Use `.getBytes()` with a charset if necessary (`"UTF-8"`).

❌ Forgetting to call `flush()` before closing buffered streams.
✅ Always `flush()` before `close()`.
