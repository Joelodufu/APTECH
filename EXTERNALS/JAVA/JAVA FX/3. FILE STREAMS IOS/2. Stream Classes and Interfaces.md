## 🧱 **2. The Stream Class Hierarchy**

Java’s I/O system is organized under the package **`java.io`**.

Below is a simplified structure:

```
                    java.lang.Object
                           |
             +-------------+-------------+
             |                           |
      java.io.InputStream          java.io.OutputStream
             |                           |
   +---------+---------+        +--------+---------+
   |                   |        |                  |
FileInputStream   ByteArrayInputStream    FileOutputStream  ByteArrayOutputStream
```

### 🧠 Key Takeaway

All these classes share a **common set of methods** because they inherit from `InputStream` and `OutputStream`.

---

## ⚙️ **3. InputStream and OutputStream Interfaces**

### 🧾 **InputStream**

This is an **abstract class** that defines methods for reading bytes of data.

| Method               | Description               |
| -------------------- | ------------------------- |
| `int read()`         | Reads one byte of data    |
| `int read(byte[] b)` | Reads bytes into an array |
| `void close()`       | Closes the input stream   |

### 🧾 **OutputStream**

This is also an **abstract class** that defines methods for writing bytes.

| Method                 | Description                |
| ---------------------- | -------------------------- |
| `void write(int b)`    | Writes one byte of data    |
| `void write(byte[] b)` | Writes bytes from an array |
| `void close()`         | Closes the output stream   |

---

## 🧪 **4. Simple Example: Reading and Writing Bytes**

### Example 1: Copy File Using Streams

```java
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class FileCopyExample {
    public static void main(String[] args) {
        try {
            FileInputStream input = new FileInputStream("input.txt");
            FileOutputStream output = new FileOutputStream("output.txt");

            int data;
            while ((data = input.read()) != -1) {
                output.write(data);
            }

            input.close();
            output.close();
            System.out.println("File copied successfully!");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

🧠 **Explanation:**

- `FileInputStream` → Reads bytes from a file.
- `FileOutputStream` → Writes bytes into another file.
- `read()` returns `-1` when it reaches the end of file.
- Always close your streams when done!

## ⚡ **5. Stream Hierarchy in Layers**

Java uses **decorator design pattern** for I/O streams.

Example structure:

```
FileInputStream → BufferedInputStream → DataInputStream
```

Each layer adds more functionality:

- **FileInputStream:** Reads raw bytes from file.
- **BufferedInputStream:** Improves speed using buffering.
- **DataInputStream:** Reads primitive types (int, double, etc).

📦 Think of it like wrapping gifts:

> The more wrappers, the more features added — but the gift inside (the raw file) remains the same.

## 🌊 **6. Introduction to Reactive Streams**

From Java 9 onward, a **new model called Reactive Streams** was introduced under the package **`java.util.concurrent.Flow`**.
Reactive Streams handle **asynchronous data flow** — especially for modern apps like APIs, sensors, and live data systems.

### 📘 Core Interfaces of `Flow`:

1. `Publisher` — Produces data
2. `Subscriber` — Consumes data
3. `Subscription` — Connects Publisher and Subscriber
4. `Processor` — Acts as both Publisher and Subscriber

---

### ⚙️ **7. Reactive Stream Example**

Let’s create a simple **Publisher–Subscriber system** using Java’s Flow API.

```java
import java.util.concurrent.Flow;

public class ReactiveStreamDemo {
    public static void main(String[] args) {
        Flow.Publisher<String> publisher = subscriber -> {
            subscriber.onSubscribe(new Flow.Subscription() {
                @Override
                public void request(long n) {
                    subscriber.onNext("Hello from Publisher!");
                    subscriber.onComplete();
                }

                @Override
                public void cancel() {
                    System.out.println("Subscription canceled.");
                }
            });
        };

        Flow.Subscriber<String> subscriber = new Flow.Subscriber<>() {
            @Override
            public void onSubscribe(Flow.Subscription subscription) {
                subscription.request(1);
            }

            @Override
            public void onNext(String item) {
                System.out.println("Received: " + item);
            }

            @Override
            public void onError(Throwable throwable) {
                throwable.printStackTrace();
            }

            @Override
            public void onComplete() {
                System.out.println("Completed!");
            }
        };

        publisher.subscribe(subscriber);
    }
}
```

🧠 **Explanation:**

- The `Publisher` sends data asynchronously.
- The `Subscriber` requests and receives that data.
- The connection between them is controlled by the `Subscription`.

This model is the foundation of **Reactive Programming** in Java — used in frameworks like **Project Reactor** and **RxJava**.

## ⚙️ **8. Stream Comparison Table**

| Stream Type         | Base Class                      | Data Type  | Direction       | Example            |
| ------------------- | ------------------------------- | ---------- | --------------- | ------------------ |
| **Input Stream**    | `InputStream`                   | Bytes      | Reads data      | `FileInputStream`  |
| **Output Stream**   | `OutputStream`                  | Bytes      | Writes data     | `FileOutputStream` |
| **Reader**          | `Reader`                        | Characters | Reads data      | `FileReader`       |
| **Writer**          | `Writer`                        | Characters | Writes data     | `FileWriter`       |
| **Reactive Stream** | `Flow.Publisher` / `Subscriber` | Any type   | Async data flow | `Flow` API         |

## 🧮 **9. Stream Example in Layers**

Let’s chain multiple stream classes together.

```java
import java.io.*;

public class ChainedStreamExample {
    public static void main(String[] args) throws IOException {
        FileInputStream file = new FileInputStream("students.dat");
        BufferedInputStream buffer = new BufferedInputStream(file);
        DataInputStream data = new DataInputStream(buffer);

        while (data.available() > 0) {
            System.out.println(data.readUTF());
        }

        data.close();
    }
}
```

🧠 **Explanation:**

- **FileInputStream** → Reads file bytes.
- **BufferedInputStream** → Buffers data for efficiency.
- **DataInputStream** → Reads data in specific types like `UTF`, `int`, `double`.

## 🧠 **10. Key Points Summary**

| Concept                        | Description                                 |
| ------------------------------ | ------------------------------------------- |
| **Stream Classes**             | Base classes for input and output in Java.  |
| **InputStream / OutputStream** | Handle byte-based data.                     |
| **Reader / Writer**            | Handle character-based data.                |
| **Reactive Streams**           | Handle asynchronous data flow.              |
| **Decorator Pattern**          | Used for combining multiple stream classes. |
| **Always Close Streams**       | To avoid resource leaks and file locks.     |
