# **Module 3: File Handling, Stream API, and Related Concepts**

## **Session 4: The File Class and Its Methods**

---

### **1. Introduction**

In this session, we focus on **Java’s `File` class**, one of the most essential tools for performing file operations such as:

- Creating files and directories
- Checking file properties
- Deleting files
- Reading metadata like name, path, and size

The `File` class is part of the **`java.io`** package and represents both files and directories in the file system.

---

### **2. What is the `File` Class?**

The `File` class is an abstraction that provides methods to interact with file and directory paths.
However, **it does not read or write data** — it only helps you access and manipulate file system properties.

> To actually read or write data, we use streams (which we’ll explore in later sessions).

---

### **3. Creating a File Object**

A `File` object can be created using one of its constructors:

```java
import java.io.File;

public class FileExample {
    public static void main(String[] args) {
        File file = new File("example.txt");
        System.out.println("File object created: " + file.getName());
    }
}
```

This does **not** create a physical file yet — it only creates a file _reference_ in Java memory.

To create an actual file, you must call:

```java
file.createNewFile();
```

---

### **4. File Creation Example**

```java
import java.io.File;
import java.io.IOException;

public class CreateFile {
    public static void main(String[] args) {
        try {
            File file = new File("data.txt");
            if (file.createNewFile()) {
                System.out.println("File created: " + file.getName());
            } else {
                System.out.println("File already exists.");
            }
        } catch (IOException e) {
            System.out.println("An error occurred.");
            e.printStackTrace();
        }
    }
}
```

---

### **5. Important Methods of the File Class**

Here’s a summary of the most commonly used methods in the `File` class:

| **Method**            | **Description**                               |
| --------------------- | --------------------------------------------- |
| `createNewFile()`     | Creates a new, empty file.                    |
| `delete()`            | Deletes the file or directory.                |
| `exists()`            | Checks if the file/directory exists.          |
| `getName()`           | Returns the name of the file/directory.       |
| `getPath()`           | Returns the path of the file/directory.       |
| `getAbsolutePath()`   | Returns the absolute pathname.                |
| `length()`            | Returns the size of the file in bytes.        |
| `isFile()`            | Returns `true` if it is a file.               |
| `isDirectory()`       | Returns `true` if it is a directory.          |
| `list()`              | Returns an array of filenames in a directory. |
| `mkdir()`             | Creates a single directory.                   |
| `mkdirs()`            | Creates multiple nested directories.          |
| `renameTo(File dest)` | Renames the file or directory.                |

---

### **6. Example: Checking File Properties**

```java
import java.io.File;

public class FileProperties {
    public static void main(String[] args) {
        File file = new File("data.txt");

        if (file.exists()) {
            System.out.println("Name: " + file.getName());
            System.out.println("Path: " + file.getPath());
            System.out.println("Absolute Path: " + file.getAbsolutePath());
            System.out.println("Writable: " + file.canWrite());
            System.out.println("Readable: " + file.canRead());
            System.out.println("File size (bytes): " + file.length());
        } else {
            System.out.println("The file does not exist.");
        }
    }
}
```

---

### **7. Example: Directory Operations**

```java
import java.io.File;

public class DirectoryExample {
    public static void main(String[] args) {
        File dir = new File("MyFolder");

        // Create directory if it doesn’t exist
        if (!dir.exists()) {
            dir.mkdir();
            System.out.println("Directory created: " + dir.getName());
        }

        // List contents
        String[] files = dir.list();
        if (files != null) {
            System.out.println("Files in directory:");
            for (String f : files) {
                System.out.println(f);
            }
        }
    }
}
```

---

### **8. Deleting a File**

```java
import java.io.File;

public class DeleteFile {
    public static void main(String[] args) {
        File file = new File("data.txt");
        if (file.delete()) {
            System.out.println("Deleted: " + file.getName());
        } else {
            System.out.println("Failed to delete the file.");
        }
    }
}
```

### **9. Real-Life Use Case**

In many applications such as:

- Logging systems
- Configuration loaders
- Backup scripts
- File upload/download managers

…the `File` class provides the foundation for handling file paths and verifying their existence before processing.

---

### **10. Key Points to Remember**

✅ The `File` class handles file system _metadata_ (not content).
✅ Always check `exists()` before performing file operations.
✅ Always handle exceptions like `IOException`.
✅ Use `mkdir()` or `mkdirs()` for creating directories.
✅ Use Streams for actual data reading/writing.
