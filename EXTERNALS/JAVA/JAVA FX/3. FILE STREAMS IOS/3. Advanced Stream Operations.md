## 🌊 **2. Introduction to Java Stream API**

Java introduced the **Stream API** in **Java 8** to handle data processing in a **functional and declarative way**.

A **Stream** in this context (not to be confused with `java.io` streams) represents:

> A sequence of elements supporting sequential and parallel aggregate operations.

You can think of it as a **pipeline** of data transformations.

Example pipeline:

```java
stream
    .filter(condition)
    .map(transformation)
    .collect(result);
```

## ⚙️ **3. takeWhile()**

### 📘 Definition:

`takeWhile(Predicate)` takes elements from a stream **while** the condition is **true**, and stops once it becomes **false**.

**Syntax:**

```java
stream.takeWhile(condition)
```

### 🧪 Example 1:

```java
import java.util.List;

public class TakeWhileExample {
    public static void main(String[] args) {
        List<Integer> numbers = List.of(1, 3, 5, 7, 2, 4, 6, 8);

        numbers.stream()
               .takeWhile(n -> n < 6)
               .forEach(System.out::println);
    }
}
```

**🧠 Explanation:**

- The stream takes elements **while** `n < 6` is true.
- It stops at `7`, because that’s the first element that breaks the rule.

**✅ Output:**

```
1
3
5
```

---

## ⚙️ **4. dropWhile()**

### 📘 Definition:

`dropWhile(Predicate)` does the **opposite** of `takeWhile()`.
It **skips** elements **while** the condition is true, then processes the rest.

**Syntax:**

```java
stream.dropWhile(condition)
```

### 🧪 Example 2:

```java
import java.util.List;

public class DropWhileExample {
    public static void main(String[] args) {
        List<Integer> numbers = List.of(1, 3, 5, 7, 2, 4, 6, 8);

        numbers.stream()
               .dropWhile(n -> n < 6)
               .forEach(System.out::println);
    }
}
```

**✅ Output:**

```
7
2
4
6
8
```

**🧠 Explanation:**

- It drops all numbers less than 6 (1, 3, 5).
- Starts processing from the first element that fails the condition (`7`).

## ⚙️ **5. ofNullable()**

### 📘 Definition:

`Stream.ofNullable()` creates a stream from a single element — **if it’s not null**.
If the element is **null**, it creates an **empty stream** (avoiding `NullPointerException`).

**Syntax:**

```java
Stream.ofNullable(object)
```

### 🧪 Example 3:

```java
import java.util.stream.Stream;

public class OfNullableExample {
    public static void main(String[] args) {
        String name = null;

        Stream.ofNullable(name)
              .forEach(System.out::println);

        System.out.println("Now with non-null:");
        Stream.ofNullable("Joel")
              .forEach(System.out::println);
    }
}
```

**✅ Output:**

```
Now with non-null:
Joel
```

**🧠 Explanation:**

- If `name` is null, the stream is empty — so no error occurs.
- It’s a clean way to handle optional values safely.

## ⚙️ **6. iterate() with Condition**

### 📘 Definition:

`Stream.iterate()` generates an **infinite or bounded** sequence of elements, often used to produce data dynamically.

Two versions exist:

| Version                     | Introduced In | Description                                  |
| --------------------------- | ------------- | -------------------------------------------- |
| `iterate(seed, f)`          | Java 8        | Generates infinite stream                    |
| `iterate(seed, hasNext, f)` | Java 9        | Generates finite stream based on a condition |

---

### 🧪 Example 4: Infinite Sequence (Java 8)

```java
import java.util.stream.Stream;

public class IterateExample {
    public static void main(String[] args) {
        Stream.iterate(1, n -> n + 1)
              .limit(5)
              .forEach(System.out::println);
    }
}
```

**✅ Output:**

```
1
2
3
4
5
```

**🧠 Explanation:**

- Starts at 1
- Keeps generating by adding 1
- `.limit(5)` stops it after 5 elements

---

### 🧪 Example 5: Bounded Sequence with Condition (Java 9+)

```java
import java.util.stream.Stream;

public class ConditionalIterateExample {
    public static void main(String[] args) {
        Stream.iterate(1, n -> n <= 10, n -> n + 2)
              .forEach(System.out::println);
    }
}
```

**✅ Output:**

```
1
3
5
7
9
```

**🧠 Explanation:**

- Starts with 1
- Keeps generating next element `n + 2`
- Stops when `n <= 10` is false

This helps avoid infinite loops without using `.limit()`.

## 💡 **7. Combining Advanced Stream Methods**

We can combine all these methods for powerful, expressive logic.

### 🧪 Example 6: Real-Life Data Filtering

```java
import java.util.List;

public class CombinedStreamExample {
    public static void main(String[] args) {
        List<Integer> numbers = List.of(10, 20, 30, 40, 5, 15, 25);

        numbers.stream()
               .dropWhile(n -> n < 25)   // skip small numbers
               .takeWhile(n -> n <= 40)  // stop when greater than 40
               .forEach(System.out::println);
    }
}
```

**✅ Output:**

```
30
40
```

## 🧠 **8. Key Differences Summary**

| Method         | Purpose                              | Stops When                                    | Introduced |
| -------------- | ------------------------------------ | --------------------------------------------- | ---------- |
| `takeWhile()`  | Takes elements until condition fails | Predicate becomes false                       | Java 9     |
| `dropWhile()`  | Skips elements while condition holds | Predicate becomes false                       | Java 9     |
| `ofNullable()` | Handles possible null elements       | Element is null → empty stream                | Java 9     |
| `iterate()`    | Generates a sequence of values       | Condition becomes false (or manually limited) | Java 8 / 9 |

## 🧰 **11. Key Takeaways**

| Concept                | Description                                         |
| ---------------------- | --------------------------------------------------- |
| **takeWhile()**        | Collects elements until a condition fails           |
| **dropWhile()**        | Skips elements until a condition fails              |
