
# **Module 3: File Handling, Stream API, and Related Concepts**

## **Session 7: InputStream Class and Its Subclasses**

---

### **1. Introduction**

In the last session, we learned how Java reads and writes **binary primitive data** using the `DataInput` and `DataOutput` interfaces.

Now, we’ll explore the **InputStream class**, which is the **foundation of all byte-based input operations** in Java.

If you’ve ever used `FileInputStream`, `BufferedInputStream`, or even `DataInputStream`, you’ve already worked with `InputStream` indirectly — it’s their parent class.

---

### **2. What is an InputStream?**

An **`InputStream`** is an **abstract class** in the `java.io` package that represents a stream of bytes coming **into** a program — from a file, network, or any input source.

Think of it as a **pipe** that carries data **from a source into your program**.

```
Data Source → InputStream → Java Application
```

---

### **3. Class Declaration**

```java
public abstract class InputStream extends Object implements Closeable
```

* It is **abstract**, so you cannot create an instance of it directly.
* Subclasses like `FileInputStream`, `ByteArrayInputStream`, and `BufferedInputStream` provide concrete implementations.

---

### **4. Key Methods of the InputStream Class**

| **Method**                             | **Description**                                                         |
| -------------------------------------- | ----------------------------------------------------------------------- |
| `int read()`                           | Reads one byte of data; returns -1 if the end of the stream is reached. |
| `int read(byte[] b)`                   | Reads bytes into an array.                                              |
| `int read(byte[] b, int off, int len)` | Reads bytes into an array with offset and length.                       |
| `long skip(long n)`                    | Skips over `n` bytes of data.                                           |
| `int available()`                      | Returns the number of bytes that can be read without blocking.          |
| `void close()`                         | Closes the stream to release resources.                                 |
| `void mark(int readlimit)`             | Marks the current position in the stream.                               |
| `void reset()`                         | Resets the stream to the last marked position.                          |
| `boolean markSupported()`              | Tests if this stream supports mark/reset.                               |

---

### **5. Example: Reading from a File**

```java
import java.io.FileInputStream;
import java.io.IOException;

public class FileInputExample {
    public static void main(String[] args) {
        try {
            FileInputStream fis = new FileInputStream("data.txt");
            int i;
            while ((i = fis.read()) != -1) {
                System.out.print((char) i);
            }
            fis.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

**Explanation:**

* Reads one byte at a time.
* `(char) i` converts each byte into a character.
* Stops reading when `read()` returns `-1`.

---

### **6. Example: Reading Multiple Bytes at Once**

```java
import java.io.FileInputStream;
import java.io.IOException;

public class ReadBytesExample {
    public static void main(String[] args) {
        try {
            FileInputStream fis = new FileInputStream("data.txt");
            byte[] buffer = new byte[100];
            int bytesRead = fis.read(buffer);
            System.out.println("Bytes read: " + bytesRead);
            System.out.println(new String(buffer, 0, bytesRead));
            fis.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

This approach is **faster** than reading one byte at a time.

### **7. Subclasses of InputStream**

The `InputStream` class has many subclasses designed for different purposes.
Here are the most important ones:

| **Subclass**             | **Description**                                                           |
| ------------------------ | ------------------------------------------------------------------------- |
| **FileInputStream**      | Reads bytes from a file.                                                  |
| **ByteArrayInputStream** | Reads bytes from a byte array in memory.                                  |
| **BufferedInputStream**  | Adds buffering for efficient reading.                                     |
| **DataInputStream**      | Reads Java primitive data types (int, double, etc.) from an input stream. |
| **ObjectInputStream**    | Deserializes objects previously written with `ObjectOutputStream`.        |
| **PipedInputStream**     | Used for reading data from another thread via a pipe.                     |

---

### **8. The FileInputStream Class**

The `FileInputStream` class is used for reading raw bytes from files.
It’s particularly useful for **binary files**, such as images, videos, and audio.

**Example:**

```java
import java.io.FileInputStream;
import java.io.IOException;

public class FileInputStreamExample {
    public static void main(String[] args) {
        try (FileInputStream fis = new FileInputStream("hello.txt")) {
            int content;
            while ((content = fis.read()) != -1) {
                System.out.print((char) content);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

Here, the `try-with-resources` ensures the stream is closed automatically.

---

### **9. The ByteArrayInputStream Class**

The `ByteArrayInputStream` allows an application to read data from a byte array as though it were an input stream.

**Example:**

```java
import java.io.ByteArrayInputStream;

public class ByteArrayInputStreamExample {
    public static void main(String[] args) {
        byte[] data = "Swift Space rocks!".getBytes();
        ByteArrayInputStream bais = new ByteArrayInputStream(data);

        int i;
        while ((i = bais.read()) != -1) {
            System.out.print((char) i);
        }
    }
}
```

This is especially useful for testing or when reading data already loaded in memory.

---

### **10. Using mark() and reset()**

Some streams allow marking a position and resetting to it later.

```java
import java.io.ByteArrayInputStream;

public class MarkResetExample {
    public static void main(String[] args) {
        byte[] data = "HELLO".getBytes();
        ByteArrayInputStream bais = new ByteArrayInputStream(data);

        System.out.print((char) bais.read()); // H
        bais.mark(0);
        System.out.print((char) bais.read()); // E
        System.out.print((char) bais.read()); // L
        bais.reset(); // back to mark
        System.out.print((char) bais.read()); // E again
    }
}
```

Output:

```
HELE
```

### **11. Real-Life Use Cases**

✅ **File reading:** Reading files like `.txt`, `.csv`, or `.dat` in Java.
✅ **Network communication:** Input streams are used in sockets to read incoming data.
✅ **Image/audio processing:** Reading raw byte data for media operations.
✅ **In-memory data testing:** Using `ByteArrayInputStream` for mock data streams.

---

### **12. Key Points to Remember**

✅ `InputStream` is the **base class** for all byte input operations.
✅ Always close streams (`close()`) to avoid resource leaks.
✅ Use `read(byte[])` for efficiency.
✅ Some streams (like `BufferedInputStream`) are faster due to internal buffering.
✅ `mark()` and `reset()` are optional — check with `markSupported()` first.
