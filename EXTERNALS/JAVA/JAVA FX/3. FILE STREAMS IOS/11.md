### **1. Introduction**

In this session, we will learn two very practical parts of Java I/O:

1. How to interact with the **console** using the `Console` class.
2. How to **read and write Strings** to files easily using character-based streams.

These two areas form the basis for building **interactive, file-based Java applications** — like command-line utilities, logging systems, and file-based configurations.

---

### **2. The `Console` Class in Java**

The `Console` class (from `java.io`) provides methods to **read user input** and **write output** in a secure and efficient way.

It’s especially useful when working with:

* Command-line applications
* Programs that require **password input** (without echoing text)
* Menu-based systems

---

### **3. Getting the Console Object**

You can obtain a `Console` object by calling:

```java
Console console = System.console();
```

⚠️ **Note:**
In some environments (like IDEs), `System.console()` may return `null`.
It works best when the program is run directly from a command prompt or terminal.

---

### **4. Reading Input Using Console**

```java
import java.io.Console;

public class ConsoleExample {
    public static void main(String[] args) {
        Console console = System.console();
        if (console != null) {
            String name = console.readLine("Enter your name: ");
            System.out.println("Hello, " + name + "!");
        } else {
            System.out.println("No console available. Try running in terminal.");
        }
    }
}
```

---

### **5. Reading Password Securely**

The `readPassword()` method hides typed characters — perfect for login simulations.

```java
import java.io.Console;
import java.util.Arrays;

public class PasswordExample {
    public static void main(String[] args) {
        Console console = System.console();
        if (console != null) {
            char[] password = console.readPassword("Enter your password: ");
            System.out.println("Password length: " + password.length);
            Arrays.fill(password, ' '); // clear from memory
        } else {
            System.out.println("Run in terminal to use password input.");
        }
    }
}
```

✅ **Good Practice:** Always clear the password array from memory once done.

---

### **6. Writing Output Using Console**

You can use:

* `console.writer()` → returns a `PrintWriter`
* `console.printf()` → prints formatted strings (like `System.out.printf()`)

Example:

```java
Console console = System.console();
if (console != null) {
    console.printf("Welcome, %s!%n", "Joel");
}
```

---

### **7. Why Use the Console Class?**

* It’s **secure** (especially for passwords).
* It supports **formatted input/output**.
* It simplifies **command-line applications**.

## **Part 2: String File Operations**

Now, let’s look at how to **read** and **write strings** to and from files.
We’ll use character-based streams — mainly **FileReader**, **FileWriter**, **BufferedReader**, and **BufferedWriter**.

---

### **8. Writing Strings to a File**

```java
import java.io.FileWriter;
import java.io.IOException;

public class WriteStringExample {
    public static void main(String[] args) {
        try (FileWriter writer = new FileWriter("message.txt")) {
            writer.write("Hello, Java learners!\n");
            writer.write("Welcome to file handling with characters.");
            System.out.println("Successfully written to the file!");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

🧠 **Concept:**
`FileWriter` automatically creates the file if it doesn’t exist and overwrites if it does.
To append data instead, use:

```java
new FileWriter("message.txt", true);
```

---

### **9. Reading Strings from a File**

```java
import java.io.FileReader;
import java.io.BufferedReader;
import java.io.IOException;

public class ReadStringExample {
    public static void main(String[] args) {
        try (BufferedReader reader = new BufferedReader(new FileReader("message.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

🧠 **Concept:**
`BufferedReader` reads text line by line efficiently — useful for large text files.

---

### **10. Combining Console Input and File Writing**

Let’s combine everything:
We’ll take user input from the console and store it in a text file.

```java
import java.io.*;
public class SaveInputToFile {
    public static void main(String[] args) {
        Console console = System.console();
        if (console != null) {
            String note = console.readLine("Write a short note: ");
            try (FileWriter writer = new FileWriter("notes.txt", true)) {
                writer.write(note + "\n");
                System.out.println("Note saved successfully!");
            } catch (IOException e) {
                System.out.println("Error saving note: " + e.getMessage());
            }
        } else {
            System.out.println("Console not available. Try running from terminal.");
        }
    }
}
```

This is a simple text logger — the foundation for applications like **journal apps**, **command-line diaries**, or **CLI-based data collection tools**.

### **11. Real-World Use Case**

✅ **System Admin Tools** — capturing user inputs and storing logs.
✅ **Simple Authentication Systems** — reading passwords securely.
✅ **Batch File Processing** — reading file names from console input.
✅ **User Feedback Systems** — storing input data in text files.

---

### **12. Best Practices**

* Always **close** your files (or use try-with-resources).
* Always **check if console is available** before using it.
* Prefer **BufferedReader/Writer** for better performance.
* Handle **IOException** properly.
* Sanitize input before saving (to avoid security issues).
