
## **Session 6: DataInput and DataOutput Interfaces**

---

### **1. Introduction**

So far, we’ve worked with `File` and `FileDescriptor` classes, which help us locate and represent files at a low level.

However, when it comes to **reading and writing primitive data types (like int, double, char, etc.)** in a portable and efficient way, Java provides two important interfaces:

* **`DataInput`**
* **`DataOutput`**

These interfaces form the **foundation for binary data handling** in Java, allowing you to store and retrieve data in the same format it was written — without worrying about text conversions.

---

### **2. What are `DataInput` and `DataOutput`?**

Both interfaces are part of the **`java.io`** package.

They define **methods to read and write Java primitive data types** (`int`, `float`, `double`, `boolean`, etc.) and `String` values in a machine-independent way.

> This means that data written on one system can be read correctly on another system — no matter the architecture.

---

### **3. Interface Hierarchy**

```
java.lang.Object
   ↳ java.io.DataInput
   ↳ java.io.DataOutput
```

These interfaces are implemented by:

* **`DataInputStream`** (implements `DataInput`)
* **`DataOutputStream`** (implements `DataOutput`)

---

### **4. The `DataInput` Interface**

The `DataInput` interface defines methods for reading data **from a binary input stream**.

#### **Commonly Used Methods in `DataInput`**

| **Method**                 | **Description**                      |
| -------------------------- | ------------------------------------ |
| `boolean readBoolean()`    | Reads one boolean value.             |
| `byte readByte()`          | Reads one byte.                      |
| `char readChar()`          | Reads a Unicode character (2 bytes). |
| `double readDouble()`      | Reads a double value.                |
| `float readFloat()`        | Reads a float value.                 |
| `int readInt()`            | Reads a 4-byte integer.              |
| `long readLong()`          | Reads an 8-byte long value.          |
| `short readShort()`        | Reads a 2-byte short value.          |
| `String readUTF()`         | Reads a string in UTF format.        |
| `void readFully(byte[] b)` | Reads bytes into the given array.    |

---

### **5. The `DataOutput` Interface**

The `DataOutput` interface defines methods for writing data **to a binary output stream**.

#### **Commonly Used Methods in `DataOutput`**

| **Method**                     | **Description**                |
| ------------------------------ | ------------------------------ |
| `void writeBoolean(boolean v)` | Writes one boolean value.      |
| `void writeByte(int v)`        | Writes one byte.               |
| `void writeChar(int v)`        | Writes a Unicode character.    |
| `void writeDouble(double v)`   | Writes a double value.         |
| `void writeFloat(float v)`     | Writes a float value.          |
| `void writeInt(int v)`         | Writes an integer value.       |
| `void writeLong(long v)`       | Writes a long value.           |
| `void writeShort(int v)`       | Writes a short value.          |
| `void writeUTF(String s)`      | Writes a string in UTF format. |

---

### **6. Example: Writing Primitive Data**

```java
import java.io.*;

public class DataOutputExample {
    public static void main(String[] args) {
        try {
            FileOutputStream fos = new FileOutputStream("student.dat");
            DataOutputStream dos = new DataOutputStream(fos);

            dos.writeInt(101);
            dos.writeUTF("Joel Odufu");
            dos.writeDouble(85.5);
            dos.writeBoolean(true);

            dos.close();
            System.out.println("Data successfully written to file.");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

**Explanation:**

* `DataOutputStream` wraps around `FileOutputStream` to enable binary writing.
* Each `write` method stores data in binary form — not as text.

---

### **7. Example: Reading Primitive Data**

```java
import java.io.*;

public class DataInputExample {
    public static void main(String[] args) {
        try {
            FileInputStream fis = new FileInputStream("student.dat");
            DataInputStream dis = new DataInputStream(fis);

            int id = dis.readInt();
            String name = dis.readUTF();
            double score = dis.readDouble();
            boolean passed = dis.readBoolean();

            dis.close();

            System.out.println("Student ID: " + id);
            System.out.println("Name: " + name);
            System.out.println("Score: " + score);
            System.out.println("Passed: " + passed);
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

**Output:**

```
Student ID: 101
Name: Joel Odufu
Score: 85.5
Passed: true
```

---

### **8. How They Work Together**

When writing:

* `DataOutputStream` writes data in a **binary format** that’s not human-readable.

When reading:

* `DataInputStream` reads the **exact same binary sequence** and converts it back into Java data types.

> ⚠️ **Important:**
> The order in which data is written must be **the same** as the order it is read.
> If you write an `int` and then a `String`, you must read an `int` first, then a `String`.

---

### **9. Example: Combining Both**

```java
import java.io.*;

public class DataInputOutputExample {
    public static void main(String[] args) {
        try {
            // Write data
            DataOutputStream dos = new DataOutputStream(new FileOutputStream("records.dat"));
            dos.writeInt(500);
            dos.writeUTF("Java Programming");
            dos.writeFloat(98.6f);
            dos.close();

            // Read data
            DataInputStream dis = new DataInputStream(new FileInputStream("records.dat"));
            System.out.println("ID: " + dis.readInt());
            System.out.println("Course: " + dis.readUTF());
            System.out.println("Score: " + dis.readFloat());
            dis.close();

        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

---

### **10. Advantages of DataInput and DataOutput**

✅ Platform-independent binary data format.
✅ Easy read/write of primitive data types.
✅ Ensures accurate reconstruction of complex data.
✅ Works seamlessly with other stream classes.

---

### **11. Limitations**

⚠️ Cannot read data unless you know the **exact order and data type** used during writing.
⚠️ Does not support **object serialization** (for that, we use `ObjectOutputStream` and `ObjectInputStream`, which we’ll cover later).

---

### **12. Real-Life Applications**

* **Database or File Storage Systems:**
  Where records are stored in binary format for performance.
* **Networking Applications:**
  Where compact data transfer between client and server is required.
* **Embedded Systems:**
  Where memory usage must be minimal, and data is stored as raw bytes.

---

### **13. Key Points to Remember**

✅ `DataInput` → Read primitive types and strings.
✅ `DataOutput` → Write primitive types and strings.
✅ Always maintain **the same order** of reading and writing.
✅ Use `DataInputStream` and `DataOutputStream` for implementation.
✅ Always **close streams** to prevent data corruption.
