# Sales Forecasting Project

## Project Overview
This project aims to forecast future sales using historical retail sales data. The goal is to build a predictive model that can forecast sales for the upcoming months based on historical sales data using machine learning techniques.

## Dataset
The dataset used in this project is the [Retail Sales Forecasting](https://www.kaggle.com/datasets/competitions/retail-sales-forecasting) dataset from Kaggle. It contains historical sales data for different stores and products. The dataset includes the following columns:
- `date`: Date of the sales transaction.
- `store`: The store where the product was sold.
- `product`: The product sold.
- `sales`: The number of sales made on the given date.
