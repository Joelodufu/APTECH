## 🧠 **2. Concept & Literature**

### **2.1 What Does It Mean to Create a Thread?**

Creating a thread means defining a **unit of execution** that can run **independently** from other parts of a program.

In Java, the `Thread` class and `Runnable` interface provide two main ways to define such independent tasks.

---

### **2.2 Ways to Create a Thread in Java**

There are **two standard methods**:

#### **A. Extending the `Thread` Class**

You can create a subclass of `Thread`, override its `run()` method, and start it using `start()`.

**Syntax Example:**

```java
class MyThread extends Thread {
    public void run() {
        System.out.println("Thread is running...");
    }
}

public class Main {
    public static void main(String[] args) {
        MyThread t = new MyThread();
        t.start();  // starts the new thread
    }
}
```

**Explanation:**

* The `run()` method defines what the thread will do.
* The `start()` method begins execution **in a separate thread**, not in the main thread.

---

#### **B. Implementing the `Runnable` Interface**

You can create a class that implements `Runnable` and pass its object to a `Thread` constructor.

**Syntax Example:**

```java
class MyRunnable implements Runnable {
    public void run() {
        System.out.println("Runnable thread is running...");
    }
}

public class Main {
    public static void main(String[] args) {
        Thread t = new Thread(new MyRunnable());
        t.start();
    }
}
```

**Why use Runnable?**

* Java supports **multiple interfaces**, but only **single inheritance**.
* So using `Runnable` allows your class to extend another class while still being threaded.

💡 *Best Practice:*
Prefer **Runnable** when your class already extends another class.

---

### **2.3 Thread Class Constructors**

Some common constructors include:

| Constructor                            | Description                                     |
| -------------------------------------- | ----------------------------------------------- |
| `Thread()`                             | Creates a new thread without a target.          |
| `Thread(Runnable target)`              | Creates a thread to run the specified target.   |
| `Thread(String name)`                  | Creates a thread with a custom name.            |
| `Thread(Runnable target, String name)` | Creates a thread with a specific task and name. |

Example:

```java
Runnable task = () -> System.out.println("Task running...");
Thread t = new Thread(task, "MyThread");
t.start();
System.out.println("Thread name: " + t.getName());
```

---

### **2.4 Why Use Threads?**

Threads enable **concurrent execution** — different tasks running simultaneously.
This improves:

* Application responsiveness
* CPU utilization
* Performance in real-time tasks (like gaming, data processing, or servers)

**Literature Context:**
In early programming, applications could only execute one task at a time. But in modern systems, especially with multi-core processors, threads let us take advantage of **true parallelism**.

---

## 🌍 **3. Real-Life Scenario**

Imagine a **web browser**:

* One thread downloads page content.
* Another renders images.
* Another listens for user clicks.
  Without threads, each of these tasks would **wait for the previous one to finish** — making the browser laggy and frustrating.

Threads make the browser smooth, interactive, and responsive.

### **Task 1: Create a Thread by Extending `Thread`**

**Objective:** Understand thread subclassing.

**Code Example:**

```java
class DownloadTask extends Thread {
    public void run() {
        for(int i = 1; i <= 5; i++) {
            System.out.println("Downloading file... " + i*20 + "%");
        }
    }
}

public class DownloadApp {
    public static void main(String[] args) {
        DownloadTask task = new DownloadTask();
        task.start();
        System.out.println("Main thread continues...");
    }
}
```

🧠 **Discussion Points:**

* Why is `start()` used instead of `run()`?
* What happens if we call `task.run()` directly instead of `task.start()`?

### **Task 2: Create a Thread Using `Runnable`**

**Objective:** Compare with previous method.

**Code Example:**

```java
class UploadTask implements Runnable {
    public void run() {
        for(int i = 1; i <= 5; i++) {
            System.out.println("Uploading file... " + i*20 + "%");
        }
    }
}

public class UploadApp {
    public static void main(String[] args) {
        Thread t = new Thread(new UploadTask());
        t.start();
        System.out.println("Main thread is active...");
    }
}
```

🧠 **Discussion Points:**

* Why is it more flexible to use `Runnable`?
* What are some benefits when using Runnable for concurrent tasks?

### **Task 3: Creating Multiple Threads**

**Objective:** Observe concurrency behavior.

**Code Example:**

```java
class Task implements Runnable {
    private String name;
    Task(String name) { this.name = name; }

    public void run() {
        for (int i = 1; i <= 3; i++) {
            System.out.println(name + " running... step " + i);
        }
    }
}

public class MultiThreadDemo {
    public static void main(String[] args) {
        Thread t1 = new Thread(new Task("Thread A"));
        Thread t2 = new Thread(new Task("Thread B"));
        Thread t3 = new Thread(new Task("Thread C"));

        t1.start();
        t2.start();
        t3.start();
    }
}
```

🧩 *In-Class Experiment:*
Run this code multiple times — notice how output order changes due to **thread scheduling**.

🧠 *Ask:* Why don’t the threads print in a predictable order?

### **Task 4: Exploring Thread Naming**

**Objective:** Understand thread identification.

**Code Example:**

```java
class Worker extends Thread {
    public Worker(String name) {
        super(name);
    }

    public void run() {
        System.out.println("Thread " + getName() + " is working...");
    }
}

public class ThreadNaming {
    public static void main(String[] args) {
        new Worker("Alpha").start();
        new Worker("Beta").start();
    }
}
```

💡 *Tip:* Thread names help in debugging and log tracing in large systems.

## 🧾 **5. Summary**

* Threads in Java can be created in **two ways:**

  1. Extending the `Thread` class.
  2. Implementing the `Runnable` interface.
* The **`run()` method** defines the thread’s behavior.
* The **`start()` method** initiates a new thread.
* **`Runnable`** is more flexible because it allows multiple inheritance and better separation of task logic.
* Threads make applications more efficient, responsive, and scalable.
