## 🧠 **2. Concept & Literature**

The `Thread` class in Java provides several **control methods** that help you start, pause, resume, or stop threads safely.

These methods allow you to **coordinate multiple threads** and control their execution order or timing.

Let’s focus on the **four most important ones** for this sub-session:

| Method           | Description                                        |
| ---------------- | -------------------------------------------------- |
| `start()`        | Begins a new thread of execution.                  |
| `run()`          | Contains the code that runs in a separate thread.  |
| `sleep(long ms)` | Pauses the thread for a specified time.            |
| `interrupt()`    | Signals a thread to stop what it’s doing (safely). |

---

### **2.1 `start()` Method**

* It **creates a new thread** and tells the JVM to call the `run()` method *in that new thread*.
* If you call `run()` directly instead, it will execute **in the current thread**, not concurrently.

📘 **Syntax:**

```java
threadObject.start();
```

💡 **Key Rule:**
A thread can only be started **once**. Calling `start()` again after it has finished throws an `IllegalThreadStateException`.

---

### **2.2 `run()` Method**

* It defines the **task or behavior** that will run in a separate thread.
* The JVM automatically calls this when `start()` is executed.

📘 **Syntax:**

```java
public void run() {
    // code that executes in the new thread
}
```

💡 **Note:**
Never call `run()` manually unless you want it to execute *in the same thread*.

---

### **2.3 `sleep()` Method**

* Used to pause a thread for a specific time (milliseconds).
* Puts the thread in a **TIMED_WAITING** state temporarily.

📘 **Syntax:**

```java
Thread.sleep(2000); // pauses for 2 seconds
```

💡 **Throws:**
`InterruptedException` — must be handled using `try-catch`.

---

### **2.4 `interrupt()` Method**

* Used to **signal** a thread to stop what it’s doing.
* Does *not forcefully terminate* the thread; instead, it sends an *interruption request*.
* The running thread can check this signal using:

  * `isInterrupted()`
  * or by catching `InterruptedException`.

📘 **Syntax:**

```java
threadObject.interrupt();
```

## 🌍 **3. Real-Life Scenario**

Imagine a **download manager**:

* `start()` begins downloading files.
* `sleep()` pauses between chunks to control bandwidth.
* `interrupt()` lets the user **cancel** a download safely.
* `run()` defines the entire download logic.

Each of these methods helps ensure the download happens efficiently and can be controlled without freezing the app.

### 🧪 **Task 1: Understanding `start()` vs `run()`**

**Objective:** Show that `start()` creates a new thread while `run()` runs in the current thread.

```java
// Example 1: start() vs run()
class MyThread extends Thread {
    public void run() {
        // Print thread name to show which one executes this method
        System.out.println("Running in thread: " + Thread.currentThread().getName());
    }
}

public class StartVsRun {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();

        // 1️⃣ Using start() - creates a NEW thread
        t1.start();  // JVM calls run() in a new thread

        // 2️⃣ Using run() - runs in the CURRENT (main) thread
        t1.run();    // No new thread created

        // Print current thread name
        System.out.println("Main thread: " + Thread.currentThread().getName());
    }
}
```

🧠 **Discussion:**

* Observe which thread prints each message.
* Notice that `start()` executes concurrently, but `run()` just runs like a normal method.

### 🧪 **Task 2: Using `sleep()` to Pause Threads**

**Objective:** Demonstrate how to delay execution and simulate time-based tasks.

```java
// Example 2: Using sleep()
class SleepDemo extends Thread {
    public void run() {
        for (int i = 1; i <= 5; i++) {
            System.out.println(getName() + " → Counting: " + i);
            try {
                // Pause for 1 second between counts
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                System.out.println(getName() + " was interrupted!");
            }
        }
    }
}

public class SleepExample {
    public static void main(String[] args) {
        SleepDemo t1 = new SleepDemo();
        SleepDemo t2 = new SleepDemo();

        t1.setName("Worker-1");
        t2.setName("Worker-2");

        // Start both threads
        t1.start();
        t2.start();

        System.out.println("Main thread continues while workers are sleeping...");
    }
}
```

💬 **Explanation:**

* Both threads print numbers simultaneously but pause using `sleep(1000)`.
* The pause creates interleaved outputs.
* This simulates real-world delays like waiting for network responses.

### 🧪 **Task 3: Handling Interruptions with `interrupt()`**

**Objective:** Learn how to stop a thread safely.

```java
// Example 3: Using interrupt() to stop a thread gracefully
class InterruptDemo extends Thread {
    public void run() {
        try {
            for (int i = 1; i <= 10; i++) {
                System.out.println("Working... step " + i);
                Thread.sleep(1000);  // Simulate long-running work
            }
        } catch (InterruptedException e) {
            // Thread interrupted during sleep
            System.out.println("Thread was interrupted! Cleaning up and exiting...");
        }
        System.out.println("Thread has ended.");
    }
}

public class InterruptExample {
    public static void main(String[] args) {
        InterruptDemo worker = new InterruptDemo();
        worker.start();

        try {
            // Let the thread run for 3 seconds
            Thread.sleep(3000);
        } catch (InterruptedException e) {}

        // Send interrupt signal
        System.out.println("Interrupting worker thread...");
        worker.interrupt();
    }
}
```

💬 **Explanation:**

* The `main()` thread interrupts the worker after 3 seconds.
* The worker catches `InterruptedException` and stops safely.
* This avoids abrupt termination (which could cause data loss or corruption).

### 🧪 **Task 4: Combining Methods in One Example**

**Objective:** Apply all learned methods in a realistic mini-project.

```java
// Example 4: Download simulation using multiple thread methods
class DownloadThread extends Thread {
    private int fileSize;

    public DownloadThread(int fileSize) {
        this.fileSize = fileSize;
    }

    public void run() {
        System.out.println(getName() + " started downloading...");

        for (int i = 1; i <= fileSize; i += 20) {
            System.out.println(getName() + " downloaded " + i + "%");
            try {
                Thread.sleep(1000); // simulate time taken per chunk
            } catch (InterruptedException e) {
                System.out.println(getName() + " was cancelled!");
                return; // stop execution gracefully
            }
        }

        System.out.println(getName() + " finished downloading successfully!");
    }
}

public class DownloadManager {
    public static void main(String[] args) {
        DownloadThread download = new DownloadThread(100);
        download.setName("FileDownloader");

        download.start(); // start download

        try {
            Thread.sleep(4000); // let it run for 4 seconds
        } catch (InterruptedException e) {}

        System.out.println("User clicked cancel...");
        download.interrupt(); // cancel download
    }
}
```

💡 **Discussion:**

* Demonstrates *start*, *sleep*, *interrupt*, and *run* in one context.
* Reflects a **real-world scenario** — user interrupts a download mid-way.
* Students can experiment with different sleep times to simulate network speed.

## 🧾 **5. Summary**

| Method        | Purpose                     | Common Use                      |
| ------------- | --------------------------- | ------------------------------- |
| `start()`     | Begins new thread execution | Launch concurrent tasks         |
| `run()`       | Defines thread behavior     | Write code for thread task      |
| `sleep(ms)`   | Temporarily pauses a thread | Simulate delay or pacing        |
| `interrupt()` | Signals a thread to stop    | Graceful shutdown of long tasks |

✅ **Key Points:**

* Always call `start()` to begin a new thread.
* `sleep()` helps manage execution timing.
* `interrupt()` should be used instead of `stop()` (which is deprecated).
* Handle `InterruptedException` gracefully to prevent program crashes.
