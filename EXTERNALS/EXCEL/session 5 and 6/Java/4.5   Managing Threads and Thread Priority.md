## 🧠 **2. Concept & Literature**

### **2.1 What is Thread Management?**

Thread management involves **controlling how multiple threads execute** so that a program performs efficiently and predictably.

The JVM’s **Thread Scheduler** decides which thread runs at a given time. However, we can **influence** this decision using **thread priorities**.

---

### **2.2 Why Thread Priority is Important**

In a multithreaded program, multiple threads often compete for CPU time.
Thread priority helps you suggest to the JVM _which threads are more important_.

🧩 Example:

- A **video player** app may have:

  - A **video rendering thread** → high priority (needs smooth playback)
  - A **file download thread** → low priority (can wait)

---

### **2.3 Thread Priority Levels**

Java assigns each thread an **integer priority** between `1` and `10`.

| Constant               | Value | Meaning          |
| ---------------------- | ----- | ---------------- |
| `Thread.MIN_PRIORITY`  | 1     | Lowest priority  |
| `Thread.NORM_PRIORITY` | 5     | Default priority |
| `Thread.MAX_PRIORITY`  | 10    | Highest priority |

> ⚠️ Note: Thread priority is **only a hint** to the scheduler — it’s not a strict rule.
> The actual behavior may differ between operating systems or JVM implementations.

---

### **2.4 Methods for Managing Priority**

#### ✅ `setPriority(int newPriority)`

Sets the thread’s priority.

```java
threadObj.setPriority(Thread.MAX_PRIORITY);
```

#### ✅ `getPriority()`

Returns the current thread’s priority.

```java
int p = threadObj.getPriority();
System.out.println("Thread priority: " + p);
```

## 🌍 **3. Real-Life Scenario**

Imagine a **music streaming app**:

- One thread handles **audio playback** (must never lag — _high priority_).
- Another thread handles **file downloads** (can run slower — _low priority_).
- A third thread updates the **UI** (medium priority).

Thread priorities help the app run smoothly by letting critical tasks take precedence.

### 🧪 **Task 1: Basic Thread Priority Example**

**Objective:** Observe how priorities affect thread execution.

```java
// Example 1: Demonstrating basic thread priorities

class PriorityDemo extends Thread {
    public void run() {
        // Print thread name and its priority
        for (int i = 1; i <= 5; i++) {
            System.out.println(Thread.currentThread().getName() +
                               " → Priority: " + Thread.currentThread().getPriority() +
                               " → Count: " + i);
        }
    }
}

public class ThreadPriorityExample {
    public static void main(String[] args) {
        PriorityDemo t1 = new PriorityDemo();
        PriorityDemo t2 = new PriorityDemo();
        PriorityDemo t3 = new PriorityDemo();

        // Setting different priorities
        t1.setPriority(Thread.MIN_PRIORITY);   // 1
        t2.setPriority(Thread.NORM_PRIORITY);  // 5
        t3.setPriority(Thread.MAX_PRIORITY);   // 10

        t1.setName("LowPriorityThread");
        t2.setName("NormalPriorityThread");
        t3.setName("HighPriorityThread");

        // Start all threads
        t1.start();
        t2.start();
        t3.start();
    }
}
```

💬 **Discussion:**

- Run this program multiple times.
- Sometimes, `HighPriorityThread` finishes first — but not always.
- This shows that **thread priority is only a suggestion**, not a guarantee.

### 🧪 **Task 2: Using `getPriority()` and Understanding Defaults**

**Objective:** Show default thread priority and how it propagates.

```java
// Example 2: Getting and propagating thread priorities

class PriorityCheck extends Thread {
    public void run() {
        System.out.println(getName() + " → Priority: " + getPriority());
    }
}

public class DefaultPriorityExample {
    public static void main(String[] args) {
        // Main thread default priority
        System.out.println("Main thread priority: " + Thread.currentThread().getPriority());

        PriorityCheck t1 = new PriorityCheck();
        PriorityCheck t2 = new PriorityCheck();

        // Not setting any priority → inherits from parent (main thread)
        t1.setName("Worker-1");
        t2.setName("Worker-2");

        t1.start();
        t2.start();
    }
}
```

💬 **Explanation:**

- By default, all threads inherit the priority of the thread that created them (usually `5`).
- If the main thread changes its priority, new threads inherit that.

### 🧪 **Task 3: Managing Thread Priority Dynamically**

**Objective:** Change priority while the program runs.

```java
// Example 3: Changing thread priority at runtime

class DynamicPriority extends Thread {
    public void run() {
        for (int i = 1; i <= 3; i++) {
            System.out.println(getName() + " running with priority " + getPriority());
            try {
                Thread.sleep(500);
            } catch (InterruptedException e) {}
        }
    }
}

public class DynamicPriorityExample {
    public static void main(String[] args) {
        DynamicPriority t1 = new DynamicPriority();
        DynamicPriority t2 = new DynamicPriority();

        t1.setName("Thread-A");
        t2.setName("Thread-B");

        t1.start();
        t2.start();

        try {
            Thread.sleep(1000);
        } catch (InterruptedException e) {}

        // Change Thread-B priority while running
        System.out.println("Changing Thread-B priority to MAX...");
        t2.setPriority(Thread.MAX_PRIORITY);
    }
}
```

💬 **Observation:**

- Thread priorities can be adjusted _on the fly_.
- However, results still depend on JVM scheduling behavior.

### 🧪 **Task 4: Simulating a Real-World Priority System**

**Scenario:**
You’re simulating an **air traffic control system**.

- Emergency aircraft threads = high priority
- Passenger aircraft threads = medium priority
- Cargo aircraft threads = low priority

```java
// Example 4: Real-world simulation using priorities

class Aircraft extends Thread {
    public Aircraft(String name, int priority) {
        setName(name);
        setPriority(priority);
    }

    public void run() {
        for (int i = 1; i <= 3; i++) {
            System.out.println(getName() + " → Priority: " + getPriority() + " → Landing Step: " + i);
            try {
                Thread.sleep(700);
            } catch (InterruptedException e) {}
        }
        System.out.println(getName() + " has landed safely ✅");
    }
}

public class AirTrafficControl {
    public static void main(String[] args) {
        Aircraft emergency = new Aircraft("EmergencyFlight", Thread.MAX_PRIORITY);
        Aircraft passenger = new Aircraft("PassengerFlight", Thread.NORM_PRIORITY);
        Aircraft cargo = new Aircraft("CargoFlight", Thread.MIN_PRIORITY);

        emergency.start();
        passenger.start();
        cargo.start();
    }
}
```

💬 **Discussion:**

- The emergency thread (high priority) _should_ get more CPU time.
- This demonstrates **priority-based scheduling** in a relatable context.

## 🧾 **5. Summary**

| Concept                                       | Description                                                            |
| --------------------------------------------- | ---------------------------------------------------------------------- |
| **Thread Priority**                           | Integer (1–10) value that hints the scheduler about thread importance. |
| **Thread Scheduler**                          | The JVM component that decides which thread runs next.                 |
| **setPriority(int)**                          | Sets a thread’s priority (1–10).                                       |
| **getPriority()**                             | Returns a thread’s current priority.                                   |
| **MIN_PRIORITY, NORM_PRIORITY, MAX_PRIORITY** | Constants representing priority levels.                                |

✅ **Key Takeaways:**

- Higher priority threads get **more chances** to run but not guaranteed.
- Default thread priority is `5`.
- Thread priority inheritance occurs when new threads are created.
- Use priorities wisely — not to replace proper synchronization.
