### 📘 **Key Definitions (Simplified for Beginners)**

| Term                          | Simple Explanation                                                                             |
| ----------------------------- | ---------------------------------------------------------------------------------------------- |
| **Data**                      | A collection of numbers, facts, or observations. Example: students’ test scores.               |
| **Frequency**                 | The number of times a value or group of values appears in a dataset.                           |
| **Class Interval**            | A group or range of data values (e.g., 0–9, 10–19). Used to simplify large data sets.          |
| **Tally**                     | A quick way of counting using marks (////). Each fifth mark closes a group of four.            |
| **Cumulative Frequency (CF)** | The running total of frequencies as you move down the table.                                   |
| **Relative Frequency**        | The ratio of each frequency to the total number of observations. Formula: `=Frequency / Total` |
| **Midpoint**                  | The average of the upper and lower boundaries of a class. Formula: `(Lower + Upper) / 2`       |

---

### 🔍 **Why Frequency Distribution Matters (Real-Life Use Cases)**

| Scenario           | Purpose of Frequency Distribution                        |
| ------------------ | -------------------------------------------------------- |
| 🏫 **Education**   | To summarize students’ scores in an exam.                |
| 🏢 **Business**    | To group daily sales into ranges for analysis.           |
| ⚕️ **Healthcare**  | To organize patients’ blood pressure readings.           |
| 🌾 **Agriculture** | To show how many farms fall within certain yield ranges. |

It helps analysts **see patterns**, such as where most data points fall (e.g., “Most students scored between 60–69”).

---

### 🧩 **Micro Example (For Understanding the Concept)**

Suppose we have test scores from **10 students**:

`45, 52, 47, 60, 66, 69, 72, 75, 75, 82`

Let’s group them into class intervals of width 10:

| Class Interval | Tally | Frequency | CF |
| -------------- | ----- | --------- | -- |
| 40–49          | ////  | 2         | 2  |
| 50–59          | //    | 2         | 4  |
| 60–69          | ////  | 3         | 7  |
| 70–79          | ////  | 3         | 10 |
| 80–89          | /     | 1         | 11 |

✅ **Total Frequency = 11**

This shows that **most students scored between 60–79**.

### 🧠 **Integral (Applied) Example**

#### Scenario:

A business recorded **daily sales (₦)** for 30 days:

`230, 250, 180, 300, 210, 260, 280, 270, 200, 240, 310, 190, 230, 250, 300, 260, 230, 280, 270, 290, 310, 330, 250, 210, 280, 300, 260, 230, 240, 220`

**Steps in Excel:**

1. **Enter Data** in a column (A2:A31).
2. **Determine Range** = Max - Min = `330 - 180 = 150`.
3. **Choose Class Width** (≈ 30).
4. **Create Intervals:** 180–209, 210–239, 240–269, 270–299, 300–329.
5. **Use FREQUENCY Function:**

   ```excel
   =FREQUENCY(A2:A31, {209,239,269,299,329})
   ```
6. **Resulting Frequency Table:**

| Class Interval | Frequency | Cumulative Frequency |
| -------------- | --------- | -------------------- |
| 180–209        | 3         | 3                    |
| 210–239        | 4         | 7                    |
| 240–269        | 5         | 12                   |
| 270–299        | 8         | 20                   |
| 300–329        | 6         | 26                   |
| 330+           | 4         | 30                   |
