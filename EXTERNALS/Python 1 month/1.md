## 1️⃣ What is Python? (15 minutes)

**Python** is a high-level, interpreted programming language that is:

- Easy to read and write
- Used in web development, data science, AI, automation, games, and more

### Why Python?

- Beginner-friendly syntax
- Large community
- Thousands of libraries

### Common Uses

- Web apps (Django, Flask)
- Data Science (Pandas, NumPy)
- AI & ML
- Automation & scripting

## 4️⃣ Comments in Python (10 minutes)

Comments are notes ignored by Python.

```python
# This is a single-line comment

"""
This is a
multi-line comment
"""
```

Why use comments?

- Explain code
- Make programs easier to understand

---

## 5️⃣ Variables & Data Types (30 minutes)

### Variables

A variable stores data.

```python
name = "Alice"
age = 25
height = 5.6
is_student = True
```

### Rules

- No spaces
- Cannot start with numbers
- Use meaningful names

---

### Data Types

| Type    | Example         |
| ------- | --------------- |
| `int`   | `10`, `-5`      |
| `float` | `3.14`, `2.0`   |
| `str`   | `"Hello"`       |
| `bool`  | `True`, `False` |

Check type:

```python
type(age)
```

---

## 6️⃣ User Input & Type Conversion (20 minutes)

### Taking Input

```python
name = input("Enter your name: ")
print("Hello", name)
```

⚠️ Input is always a **string**

### Convert Input

```python
age = int(input("Enter your age: "))
print(age + 5)
```

Other conversions:

```python
float("3.5")
str(100)
```

## 7️⃣ Basic Operators (20 minutes)

### Arithmetic Operators

| Operator | Meaning        |
| -------- | -------------- |
| `+`      | Addition       |
| `-`      | Subtraction    |
| `*`      | Multiplication |
| `/`      | Division       |
| `%`      | Modulus        |
| `**`     | Power          |

Example:

```python
a = 10
b = 3
print(a + b)
print(a ** b)
```

## 9️⃣ Common Beginner Mistakes (10 minutes)

❌ Forgetting quotes:

```python
print(Hello)
```

❌ Mixing strings & numbers:

```python
print("Age is " + 20)
```

✔ Correct:

```python
print("Age is", 20)
```
