## Module 1: Introduction to the GridView Widget

### What is GridView?

`GridView` is a scrollable widget that arranges its children in a two-dimensional grid. It’s ideal for displaying items in a tiled format, such as photo galleries, product catalogs, or dashboards.

### Key Features

- Supports static and dynamic grids.
- Variants: `GridView` (static), `GridView.builder`, `GridView.count`, `GridView.extent`, `GridView.custom`.
- Customizable scroll direction, spacing, and grid delegate.
- Constructor (basic GridView):

```dart
GridView({
  Key? key,
  Axis scrollDirection = Axis.vertical,
  bool reverse = false,
  ScrollController? controller,
  ScrollPhysics? physics,
  bool shrinkWrap = false,
  EdgeInsetsGeometry? padding,
  required SliverGridDelegate gridDelegate,
  List<Widget> children = const <Widget>[],
})
```

### Basic Example

A simple static GridView:

```dart
GridView(
  gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2,
  ),
  children: [
    Container(color: Colors.blue, child: const Center(child: Text('1'))),
    Container(color: Colors.red, child: const Center(child: Text('2'))),
    Container(color: Colors.green, child: const Center(child: Text('3'))),
    Container(color: Colors.yellow, child: const Center(child: Text('4'))),
  ],
)
```

## Module 2: GridView Variants - Count, Extent, and Builder

### GridView.count

Creates a grid with a fixed number of tiles in the cross axis.
Constructor:

```dart
GridView.count({
  Key? key,
  Axis scrollDirection = Axis.vertical,
  bool reverse = false,
  ScrollController? controller,
  ScrollPhysics? physics,
  bool shrinkWrap = false,
  EdgeInsetsGeometry? padding,
  required int crossAxisCount,
  double mainAxisSpacing = 0.0,
  double crossAxisSpacing = 0.0,
  double childAspectRatio = 1.0,
  List<Widget> children = const <Widget>[],
})
```

Example:

```dart
GridView.count(
  crossAxisCount: 3,
  children: List.generate(
    6,
    (index) => Container(
      color: Colors.primaries[index % Colors.primaries.length],
      child: Center(child: Text('Item ${index + 1}')),
    ),
  ),
)
```

### GridView.extent

Creates a grid with tiles of a maximum cross-axis extent.
Example:

```dart
GridView.extent(
  maxCrossAxisExtent: 150,
  children: List.generate(
    6,
    (index) => Container(
      color: Colors.primaries[index % Colors.primaries.length],
      child: Center(child: Text('Item ${index + 1}')),
    ),
  ),
)
```

### GridView.builder

Dynamically builds grid items on demand, ideal for large datasets.
Example:

```dart
GridView.builder(
  gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2,
    mainAxisSpacing: 8,
    crossAxisSpacing: 8,
  ),
  itemCount: 20,
  itemBuilder: (context, index) {
    return Container(
      color: index % 2 == 0 ? Colors.blue : Colors.red,
      child: Center(child: Text('Item ${index + 1}')),
    );
  },
)
```

1. What’s the difference between `GridView.count` and `GridView.extent`? (Answer: Count uses fixed column count, extent uses max tile width)

## Module 3: GridDelegate and Spacing

### SliverGridDelegate

Defines the grid’s structure. Two main types:

- `SliverGridDelegateWithFixedCrossAxisCount`: Fixed number of tiles in cross axis.
- `SliverGridDelegateWithMaxCrossAxisExtent`: Tiles with maximum cross-axis size.
  Example (Fixed Cross Axis):

```dart
GridView(
  gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2,
    mainAxisSpacing: 10,
    crossAxisSpacing: 10,
    childAspectRatio: 1.5,
  ),
  children: List.generate(
    4,
    (index) => Container(
      color: Colors.primaries[index % Colors.primaries.length],
      child: Center(child: Text('Item ${index + 1}')),
    ),
  ),
)
```

### Spacing

Control spacing with `mainAxisSpacing` (between rows) and `crossAxisSpacing` (between columns).
Example:

```dart
GridView.count(
  crossAxisCount: 2,
  mainAxisSpacing: 16,
  crossAxisSpacing: 16,
  children: List.generate(
    4,
    (index) => Container(color: Colors.blue, child: Center(child: Text('Item ${index + 1}'))),
  ),
)
```

## Module 4: Scroll Direction, Physics, and ShrinkWrap

### Scroll Direction

Controls whether the grid scrolls vertically (`Axis.vertical`) or horizontally (`Axis.horizontal`).
Example (Horizontal GridView):

```dart
GridView.count(
  scrollDirection: Axis.horizontal,
  crossAxisCount: 2,
  children: List.generate(
    6,
    (index) => Container(
      color: Colors.primaries[index % Colors.primaries.length],
      child: Center(child: Text('Item ${index + 1}')),
    ),
  ),
)
```

### Scroll Physics

Customizes scrolling behavior (e.g., `BouncingScrollPhysics`, `ClampingScrollPhysics`).
Example:

```dart
GridView.count(
  physics: const BouncingScrollPhysics(),
  crossAxisCount: 2,
  children: List.generate(
    8,
    (index) => Container(color: Colors.blue, child: Center(child: Text('Item ${index + 1}'))),
  ),
)
```

### ShrinkWrap

Forces the `GridView` to take only the space needed by its children.
Example:

```dart
GridView.count(
  shrinkWrap: true,
  crossAxisCount: 2,
  children: List.generate(
    4,
    (index) => Container(color: Colors.red, child: Center(child: Text('Item ${index + 1}'))),
  ),
)
```

1. How do you make a `GridView` scroll horizontally? (Answer: Set scrollDirection: Axis.horizontal)

## Module 5: Combining GridView with Other Widgets

### With Containers

Use `Container` for styled grid tiles.
Example:

```dart
GridView.count(
  crossAxisCount: 2,
  children: List.generate(
    4,
    (index) => Container(
      margin: const EdgeInsets.all(8),
      decoration: BoxDecoration(
        color: Colors.primaries[index % Colors.primaries.length],
        borderRadius: BorderRadius.circular(10),
        boxShadow: const [BoxShadow(color: Colors.black12, blurRadius: 4)],
      ),
      child: Center(child: Text('Item ${index + 1}')),
    ),
  ),
)
```

### With Row/Column

Nest `Row` or `Column` for complex grid items.
Example:

```dart
GridView.count(
  crossAxisCount: 2,
  children: List.generate(
    4,
    (index) => Container(
      margin: const EdgeInsets.all(8),
      color: Colors.blue,
      child: Column(
        mainAxisAlignment: MainAxisAlignment.center,
        children: [
          Text('Item ${index + 1}', style: const TextStyle(color: Colors.white)),
          const Icon(Icons.star, color: Colors.yellow),
        ],
      ),
    ),
  ),
)
```

### Best Practices

- Use `GridView.builder` for large grids to optimize performance.
- Combine with `Container` or `Card` for styled tiles.
- Test grid layouts on different screen sizes for responsiveness.
- Use `shrinkWrap` in nested layouts to avoid overflow.
- Optimize images in grids to prevent memory issues.
