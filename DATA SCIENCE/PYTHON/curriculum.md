## 📘 Application Based Programming with python

### **Module 1 – Python Foundations**

1. **Session 1 – Basics of Python**

   - Introduction to Jupyter Notebook
   - Printing, variables, and data types
   - Input/output, operators
   - Hands-on: Write a notebook that calculates BMI

2. **Session 2 – Programming Language Constructs**

   - Conditional statements (`if`, `elif`, `else`)
   - Loops (`for`, `while`)
   - List comprehensions
   - Hands-on: Write a notebook to generate Fibonacci numbers

3. **Session 3 – Introduction to Functions**

   - Defining functions
   - Arguments, return values
   - Lambda functions
   - Hands-on: Function to clean a list of strings

4. **Session 4 – Functions, Modules, and Packages**

   - Importing built-in modules (`math`, `datetime`)
   - Writing your own module
   - Installing packages via `pip` in Jupyter
   - Hands-on: Create a utility module for data cleaning

5. **Session 5 – File Handling and Exception Handling**

   - Reading/Writing text and CSV files
   - Try/except blocks
   - Hands-on: Read a dataset, handle missing file errors

---

### **Module 2 – Working with Data**

6. **Session 6 – Regular Expressions and Tokenization**

   - Using `re` library
   - Tokenization with `nltk`/`spaCy`
   - Hands-on: Clean and tokenize customer reviews

7. **Session 7 – Web Development with Flask (Intro only)**
   _(Optional, since Flask is not always needed in Data Science, but we can make a simple API for ML models)_

   - Create a minimal Flask app
   - Hands-on: API endpoint returning predictions

8. **Session 8 – Web Scraping in Python**

   - `requests`, `BeautifulSoup`, `selenium` basics
   - Hands-on: Scrape book titles and prices from a website

9. **Session 9 – GUI Programming in Tkinter** _(Optional for Data Science, can be a side project)_

   - Build a simple Tkinter form
   - Hands-on: Simple calculator GUI

---

### **Module 3 – Data Science Core**

10. **Session 10 – Database Integration with Python**

    - SQLite with `sqlite3`
    - Connecting to MySQL/PostgreSQL
    - Hands-on: Query dataset from SQLite

11. **Session 11 – Data Handling Using Pandas**

    - Series, DataFrames
    - Indexing, filtering, groupby
    - Hands-on: Analyze sales dataset

12. **Session 12 – Data Visualization in Python**

    - `matplotlib`, `seaborn` basics
    - Hands-on: Plot sales trends

13. **Session 13 – Data Processing Techniques in Machine Learning**

    - Data cleaning, missing values, scaling
    - Feature engineering
    - Hands-on: Preprocess Titanic dataset

14. **Session 14 – Introduction to Machine Learning**

    - Supervised vs unsupervised
    - Scikit-learn pipeline
    - Hands-on: Train a decision tree classifier

15. **Session 15 – Regression Techniques**

    - Linear regression, multiple regression
    - Evaluation metrics (RMSE, R²)
    - Hands-on: Predict housing prices
