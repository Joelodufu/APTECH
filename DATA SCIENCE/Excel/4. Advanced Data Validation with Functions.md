## 🧩 **1. Introduction**

In previous modules, we learned basic validation methods (number limits, lists, and date rules).
This module builds on that by introducing **custom formula-based validations** — the most powerful and flexible type of data validation.

> 💡 Formula-based validation lets Excel decide if input is valid using logical tests.

For example:

```excel
=ISNUMBER(A2)
```

Only allows numeric entries in cell A2.

---

## 🧠 **2. Built-in Logical Test Functions for Validation**

### A. **ISBLANK()**

**Purpose:** Checks if a cell is empty.
**Syntax:**

```excel
=ISBLANK(value)
```

**Returns:**

- `TRUE` if the cell is blank
- `FALSE` if it contains any data

**Example Validation Rule:**
To **prevent blank entries** in cell A2:

```excel
=NOT(ISBLANK(A2))
```

---

### B. **ISNUMBER()**

**Purpose:** Checks if a cell contains a numeric value.
**Syntax:**

```excel
=ISNUMBER(value)
```

**Example Validation Rule:**
To ensure a cell contains only numbers:

```excel
=ISNUMBER(A2)
```

> 💡 Combine with other conditions:

```excel
=AND(ISNUMBER(A2),A2>0)
```

This allows only **positive numbers**.

---

### C. **ISTEXT()**

**Purpose:** Checks if the cell contains text.
**Syntax:**

```excel
=ISTEXT(value)
```

**Example Validation Rule:**
Allow **only text** (e.g., for names or departments):

```excel
=ISTEXT(A2)
```

> 💡 Combine with `NOT(ISBLANK())`:

```excel
=AND(ISTEXT(A2),NOT(ISBLANK(A2)))
```

Ensures text is required and not blank.

---

## 🧩 **3. Combining Multiple Validation Functions**

Custom validation formulas often use **logical functions** like:

- `AND()` → All conditions must be TRUE
- `OR()` → At least one condition must be TRUE
- `NOT()` → Negates a condition

### Example 1: Restrict entry to numbers between 10 and 100

```excel
=AND(ISNUMBER(A2),A2>=10,A2<=100)
```

### Example 2: Require text that is not blank

```excel
=AND(ISTEXT(A2),NOT(ISBLANK(A2)))
```

### Example 3: Allow either “N/A” or a valid number

```excel
=OR(A2="N/A",ISNUMBER(A2))
```

## 🔍 **6. Lookup Functions with Data Validation**

### Purpose

Combine **data validation lists** with **lookup tables** to create dynamic dropdowns.
Example: Selecting a _Department_ automatically filters _Roles_ available in that department.

---

### Step-by-Step: Dependent Dropdown Lists

#### 1️⃣ Prepare Lookup Table

In the **Lookup_Table** sheet, set up:

| Department | Roles                                  |
| ---------- | -------------------------------------- |
| HR         | Recruiter, HR Manager, Payroll Officer |
| IT         | Developer, Network Admin, IT Support   |
| Sales      | Sales Rep, Account Manager             |
| Admin      | Office Assistant, Secretary            |

---

#### 2️⃣ Name Each Department Range

1. Select `B2:B4` → Name it `HR`
2. Select `C2:C4` → Name it `IT`
3. Select `D2:D4` → Name it `Sales`
4. Select `E2:E4` → Name it `Admin`

(Use **Formulas → Define Name**)

---

#### 3️⃣ Create Primary Validation (Department)

In your data entry sheet:

1. Select the **Department** cell.
2. Data → Data Validation → **List**.
3. Source:

   ```
   =Lookup_Table!$A$2:$A$5
   ```

4. Click **OK**.

---

#### 4️⃣ Create Dependent Validation (Role)

In the **Role** cell:

1. Data → Data Validation → **List**.
2. Source:

   ```
   =INDIRECT(B2)
   ```

   _(Assuming Department is in B2)_

This tells Excel to look for the named range that matches the department name.

✅ Now, when you select “IT” in Department, the Role list automatically shows only IT-related options!

---

## ⚙️ **7. Using IS Functions with Lookup**

You can validate lookup results to ensure they exist before entry.

### Example:

Only allow valid department names that exist in a lookup range:

```excel
=COUNTIF(Lookup_Table!A:A,A2)>0
```

If a user types a department not in the lookup, Excel will block it.

## 🧠 **9. Common Errors & Fixes**

| Error                          | Cause                                    | Fix                                |
| ------------------------------ | ---------------------------------------- | ---------------------------------- |
| `#NAME?` in validation         | Named range not defined                  | Check **Formulas → Name Manager**  |
| Validation formula not working | Wrong relative reference                 | Use absolute `$` references        |
| Dropdown not updating          | INDIRECT function not pointing correctly | Verify parent cell address         |
| Validation copied incorrectly  | Copy-paste overwrote validation          | Use **Paste Special → Validation** |

## 💡 **10. Advanced Formula Ideas**

| Use Case                     | Formula                         | Description      |
| ---------------------------- | ------------------------------- | ---------------- |
| Prevent empty text           | `=NOT(ISBLANK(A2))`             | No blank entries |
| Restrict to whole numbers    | `=AND(ISNUMBER(A2),A2=INT(A2))` | Integer only     |
| Require date in current year | `=YEAR(A2)=YEAR(TODAY())`       | This year only   |
| Accept text or “N/A”         | `=OR(ISTEXT(A2),A2="N/A")`      | Allows either    |

## 🧾 **11. Summary**

| Function       | Purpose                  | Example                           |
| -------------- | ------------------------ | --------------------------------- |
| **ISBLANK()**  | Checks for empty cells   | `=NOT(ISBLANK(A2))`               |
| **ISNUMBER()** | Validates numeric values | `=ISNUMBER(A2)`                   |
| **ISTEXT()**   | Validates text entries   | `=ISTEXT(A2)`                     |
| **INDIRECT()** | Links dependent lists    | `=INDIRECT(B2)`                   |
| **COUNTIF()**  | Confirms lookup matches  | `=COUNTIF(Lookup_Table!A:A,A2)>0` |
