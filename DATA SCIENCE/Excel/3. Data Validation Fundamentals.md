
# 📘 **Module 3: Data Validation Fundamentals**

## 🎯 **Learning Objective**

By the end of this module, learners should be able to:

* Understand the purpose and benefits of Data Validation
* Apply built-in validation rules for text, numbers, and dates
* Create dropdown lists for controlled data entry
* Add input messages and error alerts to guide users

---

## 🧩 **1. Introduction to Data Validation**

**Data Validation** in Excel is a feature that helps you **control what can or cannot be entered into a cell**.
It ensures that users input data that fits specific criteria — reducing errors and maintaining data consistency.

> 💡 Example: You can prevent users from entering an age below 18 or entering text where a number is required.

---

## 🧠 **2. Why Use Data Validation?**

| Benefit           | Description                                             |
| ----------------- | ------------------------------------------------------- |
| **Accuracy**      | Prevents invalid or out-of-range data                   |
| **Consistency**   | Enforces uniform data entry across a worksheet          |
| **Efficiency**    | Reduces time spent on data cleaning                     |
| **User Guidance** | Helps users know what’s expected before they enter data |

---

## 🧰 **3. Exploring the Data Validation Tool**

To open the Data Validation window:

1. Select the cell or range where you want validation
2. Go to **Data → Data Tools → Data Validation**

The dialog box has three main tabs:

| Tab               | Purpose                                        |
| ----------------- | ---------------------------------------------- |
| **Settings**      | Define the type and range of valid data        |
| **Input Message** | Display a hint when a user selects the cell    |
| **Error Alert**   | Display a message when invalid data is entered |

---

## 🧮 **4. Built-in Data Validation Rules**

Here are the most common built-in options in the **Settings** tab:

| Validation Type  | Description                           | Example                     |
| ---------------- | ------------------------------------- | --------------------------- |
| **Whole Number** | Restrict entry to integers            | Between 18 and 65           |
| **Decimal**      | Allow decimal numbers within a range  | Between 0.5 and 10.0        |
| **List**         | Create a dropdown selection list      | HR, IT, Sales, Admin        |
| **Date**         | Restrict to a valid date range        | Before today                |
| **Time**         | Restrict to a specific time range     | Between 8:00 AM and 5:00 PM |
| **Text Length**  | Restrict number of characters         | Max 20 characters           |
| **Custom**       | Use a formula to define your own rule | `=ISNUMBER(A2)`             |

## 🧩 **5. Practical Setup in Workbook**

Use the **`Validation_Basics`** sheet from your workbook
(`Excel_Automation_Class.xlsx`).

### 🎯 Goal:

Set up validation for each column in the table below:

| Column              | Rule                         | Validation Type  |
| ------------------- | ---------------------------- | ---------------- |
| **Name**            | Must not be blank            | Custom           |
| **Age**             | Between 18 and 65            | Whole number     |
| **Email**           | Must contain “@”             | Custom (formula) |
| **Date of Joining** | Must not be a future date    | Date             |
| **Department**      | Must be selected from a list | List             |

---

### 🧭 **Step-by-Step Instructions**

#### A. **Validate Age (Whole Number)**

1. Select the **Age** column (e.g., `B2:B100`).
2. Go to **Data → Data Validation → Settings tab**.
3. Choose **Whole Number**.
4. Set **Minimum = 18**, **Maximum = 65**.
5. (Optional) Add an input message:

   * Title: `Valid Age Range`
   * Message: `Enter age between 18 and 65 only.`

---

#### B. **Validate Department (List)**

1. Select the **Department** column.
2. Go to **Data → Data Validation → Settings tab**.
3. Choose **List**.
4. In the **Source** box, type:

   ```
   HR, IT, Sales, Admin
   ```
5. Check **In-cell dropdown** → Click **OK**.

Now users can only select one of these values.

---

#### C. **Validate Email (Custom Rule)**

1. Select the **Email** column.
2. Open **Data Validation → Settings tab**.
3. Choose **Custom**.
4. In the **Formula** box, enter:

   ```excel
   =ISNUMBER(SEARCH("@",C2))
   ```
5. Add an **Error Alert**:

   * Title: `Invalid Email`
   * Message: `Email must contain @ symbol.`

---

#### D. **Validate Date of Joining (Date)**

1. Select the **Date of Joining** column.
2. Choose **Date** as validation type.
3. Under “Data,” choose **less than or equal to**.
4. In the **End date** box, enter:

   ```
   =TODAY()
   ```

This ensures users can’t enter future dates.

---

#### E. **Prevent Blank Names (Custom Rule)**

1. Select the **Name** column.
2. Choose **Custom** validation.
3. Use this formula:

   ```excel
   =NOT(ISBLANK(A2))
   ```
4. Add an **Error Alert** saying:
   *“Name field cannot be left blank.”*

## 💬 **6. Adding Input Messages**

Input messages appear when a user clicks into a validated cell — guiding them before they type.

### Example:

For the **Age** field:

* Title: *“Age Requirement”*
* Message: *“Enter a number between 18 and 65.”*

They disappear once the user moves away from the cell.

---

## ⚠️ **7. Error Alerts**

When invalid data is entered, Excel can display different alert styles:

| Style                | Description                     | Example           |
| -------------------- | ------------------------------- | ----------------- |
| **Stop (⛔)**         | Prevents entry completely       | Age below 18      |
| **Warning (⚠️)**     | Allows entry after confirmation | Date out of range |
| **Information (ℹ️)** | Accepts entry but notifies user | Text too long     |

To set an alert:

1. Go to **Data → Data Validation → Error Alert tab**
2. Choose a style and enter a title and message.

## 🧠 **9. Troubleshooting Common Validation Issues**

| Issue                                  | Cause                              | Fix                                    |
| -------------------------------------- | ---------------------------------- | -------------------------------------- |
| Data validation not working            | Cell already contains invalid data | Clear contents before applying         |
| Dropdown not showing                   | “In-cell dropdown” unchecked       | Enable it in settings                  |
| Validation disappears after copy-paste | Overwriting validation             | Use **Paste Special → Validation**     |
| Rule not applying                      | Wrong cell reference               | Use absolute references (e.g., `$A$2`) |

---

## 💡 **10. Best Practices for Data Validation**

✅ **Do:**

* Apply validation before sharing templates
* Combine multiple validation types (e.g., List + Custom)
* Use named ranges for dynamic lists

🚫 **Avoid:**

* Hardcoding formulas that depend on specific rows
* Copy-pasting data from external sources without checking rules

## 🧩 **12. Trainer’s Tips**

* Demonstrate each rule live (especially list and date).
* Show how an error alert prevents incorrect entry.
* Encourage learners to create one **combined rule** using a formula.
* Explain how data validation complements macros (e.g., validating data before automation).

---

## 🧠 **13. Key Takeaways**

* Data Validation is Excel’s built-in quality control system.
* It ensures accurate, consistent, and clean data entry.
* You can combine formulas like `ISNUMBER()`, `ISBLANK()`, or `SEARCH()` for customized rules.
* Always include **input messages** and **error alerts** for user guidance.
