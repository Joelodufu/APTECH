# **Exercise 1: Integration with AI Tools in Power BI (Using Sales Dataset)**

### **Objective**

Students will learn to integrate Power BI’s **built-in AI visuals** (Q&A, Decomposition Tree, Key Influencers, Smart Narratives) to extract insights directly from the dataset.

---

### **Step 1: Load the Dataset**

1. Open **Power BI Desktop**.
2. Click **Home → Get Data → Text/CSV**.
3. Select **PowerBI_AI_SalesDataset.csv** (downloaded earlier).
4. Load the data into Power BI.

---

### **Step 2: Q&A Visual (Natural Language Queries)**

1. Go to **Insert → Q&A Visual**.
2. In the Q&A box, type:

   * *“Total sales by region”*
   * *“Average SatisfactionScore by ProductCategory”*
   * *“Top 5 customers by Total Sales”*
3. If needed, create a **calculated column** first:

   ```DAX
   TotalSales = Sales[Quantity] * Sales[UnitPrice]
   ```

   Then re-run the queries.

📌 *Q&A lets students discover insights without manually building visuals.*

---

### **Step 3: Decomposition Tree**

1. Insert a **Decomposition Tree** visual.
2. Set **TotalSales** as the *Analyze* field.
3. Add **Region → ProductCategory → SalesRep** as *Explain by* fields.
4. Expand step by step to see which factor drives sales the most.

📌 *Students will see, for example, whether a region, product category, or rep contributes most to revenue.*

---

### **Step 4: Key Influencers**

1. Insert a **Key Influencers Visual**.
2. Set **SatisfactionScore** as the *Analyze* field.
3. Add **ProductCategory, Region, UnitPrice, SalesRep** as *Explain by* fields.
4. Observe which variables influence customer satisfaction.

📌 *E.g., Electronics might have higher satisfaction than Furniture.*

---

### **Step 5: Smart Narrative**

1. Insert a **Smart Narrative** visual.
2. Power BI automatically generates text insights like:

   * “The average Total Sales is $X.”
   * “North region contributed the highest revenue.”
   * “Customer satisfaction is higher in Clothing.”

📌 *Students can edit the narrative to customize auto-generated insights.*

---

### **Hands-On Task**

1. Use **Q&A** to answer:

   * *Which SalesRep had the highest sales in 2024?*
2. Use the **Decomposition Tree** to drill into *Revenue by Region → ProductName*.
3. Use **Key Influencers** to identify:

   * *What drives higher SatisfactionScore?*
4. Add a **Smart Narrative** that summarizes your dashboard.

---

### **Expected Learning Outcome**

By the end of this exercise, students will:
✅ Use AI visuals in Power BI to query, explain, and narrate insights.
✅ Automatically identify key patterns in the dataset without building complex queries.
✅ Be able to communicate insights with **AI-generated explanations**.
