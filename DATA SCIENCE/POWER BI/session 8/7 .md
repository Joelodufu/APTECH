# **Exercise 6: Development of Advanced Visual Reports**

### **Objective**

Students will learn how to:

* Use advanced Power BI visuals (beyond bar/line charts).
* Combine multiple visuals into a cohesive **executive-style dashboard**.
* Apply **bookmarks, drill-through, and slicers** for interactive reports.
* Tell a data story with the Sales dataset.

---

### **Step 1: Prepare the Dataset**

1. Use **Sales_Missing.csv** (cleaned in Exercise 5).
2. Ensure DAX measures from Exercise 4 are available:

   * TotalRevenue
   * AvgTransaction
   * Profit
   * AvgSatisfaction
   * HighValueOrders

---

### **Step 2: Add Advanced Visuals**

1. **Decomposition Tree**

   * Add → *Decomposition Tree*.
   * Analyze **TotalRevenue** → break down by `Region → ProductCategory → SalesRep`.
   * 📌 Shows drill-down analysis for revenue drivers.

2. **Waterfall Chart**

   * Add → *Waterfall Chart*.
   * Display **Profit by ProductCategory**.
   * 📌 Shows contribution of each category to profit.

3. **Map Visualization** (if Region data exists)

   * Add → *Map* visual.
   * Show **TotalRevenue by Region**.
   * 📌 Provides geographic sales distribution.

4. **Gauge Chart**

   * Insert → *Gauge*.
   * Show **AvgSatisfaction vs Target (4.5)**.
   * 📌 Measures customer experience health.

---

### **Step 3: Add Interactivity**

1. **Slicers**

   * Add slicers for `Region`, `ProductCategory`, `TransactionDate`.
   * 📌 Allows filtering across all visuals.

2. **Drill-through Page**

   * Create a *new page*.
   * Add a detail table (TransactionID, CustomerName, ProductName, TotalSales).
   * Enable *Drill-through → Region*.
   * 📌 Right-clicking on a region in visuals drills into detailed transactions.

3. **Bookmarks for Storytelling**

   * Create *Bookmark 1*: Overview Dashboard.
   * Create *Bookmark 2*: Profit Deep Dive.
   * Add a *Button* → assign bookmarks for storytelling navigation.

---

### **Step 4: Assemble an Executive Dashboard**

**Page Layout Example:**

* **Top row (KPI cards):** TotalRevenue, Profit, AvgTransaction, AvgSatisfaction.
* **Middle row (visuals):** Map (by Region), Waterfall (Profit by Category), Decomposition Tree (Revenue drivers).
* **Bottom row (interaction):** Slicers + Drill-through button.

📌 Make it **clean, minimal, and mobile-friendly**.

---

### **Step 5: Validate and Compare**

* Filter the dashboard by *North Region only* → analyze trends.
* Change slicer to *Electronics only* → see how revenue & satisfaction shift.
* Compare results with *full dataset* → highlight differences.

---

### **Hands-On Task**

1. Build a **Decomposition Tree** for TotalRevenue.
2. Create a **Waterfall chart** for Profit by ProductCategory.
3. Add a **Map** for sales distribution.
4. Insert slicers for interactive filtering.
5. Design a **one-page executive dashboard** combining all visuals.

---

### **Expected Learning Outcome**

By the end of this exercise, students will:
✅ Design **advanced visualizations** (decomposition tree, waterfall, map, gauge).
✅ Use slicers, drill-through, and bookmarks for **interactive exploration**.
✅ Build a **professional, executive-level dashboard**.
✅ Apply storytelling techniques to highlight insights.
