# **Exercise 5: Handling Missing Data (Using Sales Dataset)**

### **Objective**

Students will learn how to:

- Identify missing data in Power BI.
- Apply Power Query transformations to clean missing values.
- Use DAX functions (`COALESCE`, `IF`, `ISBLANK`) to handle missing values in calculations.
- Compare insights before vs after cleaning.

---

### **Step 1: Simulate Missing Data**

Since the provided dataset is complete, the instructor can **introduce missing values**:

1. Open `PowerBI_AI_SalesDataset.csv` in Excel (or inside Power Query).
2. Randomly delete some values from:

   - **UnitPrice**
   - **Region**
   - **SatisfactionScore**

3. Save the modified file as **Sales_Missing.csv**.
4. Load it into Power BI.

📌 This prepares the dataset for the exercise.

---

### **Step 2: Detect Missing Data in Power Query**

1. In **Home → Transform Data → Power Query Editor**.
2. Check for **blank/null values** in `UnitPrice`, `Region`, and `SatisfactionScore`.
3. Apply:

   - **Remove Rows** → remove rows with nulls.
   - OR **Replace Values** → replace nulls with “Unknown” (for text fields like Region).
   - OR **Fill Down/Up** → for filling missing values based on surrounding rows.

---

### **Step 3: Handle Missing Data with DAX**

Instead of cleaning at source, DAX can manage null values:

1. **Replace Null UnitPrice with 100**

   ```DAX
   UnitPrice_Clean = COALESCE(Sales[UnitPrice], 100)
   ```

2. **Replace Null Region with “Unknown”**

   ```DAX
   Region_Clean = IF(ISBLANK(Sales[Region]), "Unknown", Sales[Region])
   ```

3. **Handle Missing SatisfactionScore by Replacing with Average**

   ```DAX
   Satisfaction_Clean =
   IF(
       ISBLANK(Sales[SatisfactionScore]),
       AVERAGE(Sales[SatisfactionScore]),
       Sales[SatisfactionScore]
   )
   ```

---

### **Step 4: Compare Before vs After**

1. Create a **table visual** with: CustomerName, Region, UnitPrice, SatisfactionScore.
2. Duplicate it, but use **Region_Clean, UnitPrice_Clean, Satisfaction_Clean**.
3. Compare how missing values affect insights.

📌 Example: Avg. Satisfaction before cleaning = 3.8, after cleaning = 4.1.

---

### **Step 5: Data Quality Report**

1. Create a **card visual** → count rows with missing values:

   ```DAX
   MissingRegions = COUNTROWS(FILTER(Sales, ISBLANK(Sales[Region])))
   ```

2. Create a bar chart → Number of missing values per column.

---

### **Hands-On Task**

1. Introduce missing values into the dataset (UnitPrice, Region, SatisfactionScore).
2. Use Power Query to replace missing **Region** with “Unknown”.
3. Use DAX (`COALESCE`) to handle missing **UnitPrice**.
4. Replace missing **SatisfactionScore** with the column average.
5. Build a **Before vs After Comparison report** showing improvements.

---

### **Expected Learning Outcome**

By the end of this exercise, students will:
✅ Identify missing values in Power BI.
✅ Apply **Power Query cleaning techniques**.
✅ Use **DAX functions** (`COALESCE`, `IF`, `ISBLANK`) for null handling.
✅ Build a simple **Data Quality Report** to monitor missing data.
