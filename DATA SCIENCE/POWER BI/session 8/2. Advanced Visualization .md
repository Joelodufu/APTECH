# **Exercise 2: Advanced Data Visualization (Using Sales Dataset)**

### **Objective**

Students will learn how to create **professional-grade visualizations** with conditional formatting, custom visuals, bookmarks, and drill-throughs.

---

### **Step 1: Load Dataset (if not already done)**

1. Open **Power BI Desktop**.
2. Ensure `PowerBI_AI_SalesDataset.csv` is loaded (if not, import it again).
3. Create a calculated column for total sales:

   ```DAX
   TotalSales = Sales[Quantity] * Sales[UnitPrice]
   ```

---

### **Step 2: Funnel Chart (Sales Pipeline Example)**

1. Go to **Visualizations Pane → Funnel Chart**.
2. Drag **ProductCategory** to _Group_.
3. Drag **TotalSales** to _Values_.
4. The funnel now shows total sales by product category, from highest to lowest.

📌 _This simulates a sales pipeline, where Electronics → Furniture → Clothing can be compared._

---

### **Step 3: Conditional Formatting (Highlighting Performance)**

1. Insert a **Table visual** with:

   - CustomerName
   - Region
   - TotalSales

2. Right-click **TotalSales column → Conditional Formatting → Background Color**.
3. Choose a color scale (e.g., low = red, high = green).

📌 _Students will see instantly which customers contribute most/least._

---

### **Step 4: Custom Visuals from AppSource**

1. Go to **Visualizations → Get More Visuals (AppSource)**.
2. Install one of these:

   - **Sankey Chart** → to show flow of sales from Region → ProductCategory → SalesRep.
   - **Word Cloud** → for most frequent product names.

3. Insert the custom visual and map fields accordingly.

📌 _Example: Sankey showing "North → Electronics → Sarah Johnson → $X in sales."_

---

### **Step 5: Drill-Through (Customer Insights)**

1. Create a new **Report Page → Rename as Customer Details**.
2. Add fields: CustomerName, Region, ProductCategory, TotalSales, SatisfactionScore.
3. Go back to main dashboard.
4. Add **CustomerName field to Drill-through Filters**.
5. Now right-click a customer in the main table → Drill-through → Customer Details.

📌 _This lets students jump into detailed customer insights dynamically._

---

### **Step 6: Bookmarks (Interactive Storytelling)**

1. On the main dashboard, create 2 layouts:

   - **Summary View**: Funnel + KPI Cards.
   - **Detailed View**: Customer Table + Sankey Chart.

2. Go to **View → Bookmarks Pane → Add Bookmark** for each layout.
3. Add **Buttons → Assign actions → Bookmark**.

📌 _Students can now switch between executive summary and details with one click._

---

### **Hands-On Task**

1. Create a **funnel chart** showing total sales by ProductCategory.
2. Build a **Sankey chart** showing Region → ProductCategory → SalesRep.
3. Apply **conditional formatting** to highlight top customers.
4. Add a **Drill-through page** to view customer-level details.
5. Use **Bookmarks** to create a switch between _Summary_ and _Details_.

---

### **Expected Learning Outcome**

By the end of this exercise, students will:
✅ Build **custom and advanced visuals** in Power BI.
✅ Apply **conditional formatting** for better data storytelling.
✅ Use **Drill-throughs** for deeper analysis.
✅ Use **Bookmarks** to create interactive dashboards for executives vs analysts.
