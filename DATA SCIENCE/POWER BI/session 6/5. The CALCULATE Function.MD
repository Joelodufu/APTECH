# **Module 5: The CALCULATE Function**

## **5.1 Concept**

`CALCULATE` is the most powerful DAX function.
It **modifies the filter context** of a calculation, allowing you to create:

* Filtered measures
* Time intelligence calculations
* Conditional aggregations

**Syntax:**

```DAX
CALCULATE(<expression>, <filter1>, <filter2>, …)
```

* `<expression>`: measure or aggregation to calculate
* `<filters>`: optional conditions or modified context

---

## **5.2 Practical Examples**

**Example 1: Total Sales for a Category**

```DAX
Total Fashion Sales :=
CALCULATE(
    SUM(Sales[SalesAmount]),
    Sales[Category] = "Fashion"
)
```

🔹 Calculates sum of sales **only for Fashion category**.

---

**Example 2: High Value Sales**

```DAX
High Value Sales :=
CALCULATE(
    SUM(Sales[SalesAmount]),
    Sales[SalesAmount] > 5000
)
```

🔹 Sums only orders exceeding 5000.

---

**Example 3: Sales Last Year**

```DAX
Sales Last Year :=
CALCULATE(
    SUM(Sales[SalesAmount]),
    DATEADD(Sales[OrderDate], -1, YEAR)
)
```

🔹 Shifts date context to previous year.

---

**Example 4: Electronics Sales This Month**

```DAX
Electronics Sales This Month :=
CALCULATE(
    SUM(Sales[SalesAmount]),
    Sales[Category] = "Electronics",
    MONTH(Sales[OrderDate]) = MONTH(TODAY())
)
```

🔹 Combines multiple filters for dynamic reporting.

## **5.5 Exercise Answers (For Trainers)**

1. **Total Electronics Sales**

```DAX
Total Electronics Sales :=
CALCULATE(
    SUM(Sales[SalesAmount]),
    Sales[Category] = "Electronics"
)
```

* Expect largest sales values in Electronics (Laptops, Phones).

---

2. **High Profit Orders**

```DAX
High Profit Orders :=
CALCULATE(
    SUM(Sales[Profit]),
    Sales[Profit] > 2000
)
```

* Only a subset of Electronics and high-value Fashion orders.

---

3. **Fashion Sales Last Year**

```DAX
Fashion Sales Last Year :=
CALCULATE(
    SUM(Sales[SalesAmount]),
    Sales[Category] = "Fashion",
    DATEADD(Sales[OrderDate], -1, YEAR)
)
```

* Returns total Fashion sales for previous year; smaller than Electronics usually.

---

4. **Fast Shipping Electronics**

```DAX
Fast Electronics Sales :=
CALCULATE(
    SUM(Sales[SalesAmount]),
    Sales[Category] = "Electronics",
    DATEDIFF(Sales[OrderDate], Sales[ShipDate], DAY) <= 3
)
```

* Only includes orders delivered in 3 days or less.

---

5. **Non-Discounted Sales**

```DAX
Non-Discounted Sales :=
CALCULATE(
    SUM(Sales[SalesAmount]),
    Sales[Discount] = 0
)
```

* Shows total revenue from full-price sales.
