# **Module 7: Iterators Deep Dive (Advanced X Functions)**

## **7.1 Concept**

Iterators like `SUMX`, `AVERAGEX`, `MAXX`, `MINX`, and `RANKX` allow **row-by-row calculations** that go beyond basic aggregation.

- Useful for **ranking, filtering, and conditional aggregations**
- Can be combined with `CALCULATE` for **context-aware calculations**
- Essential for creating **advanced KPIs** in Power BI

---

## **7.2 Key Functions Overview**

| Function                            | What it Does                   | Example (on dataset)                                                |
| ----------------------------------- | ------------------------------ | ------------------------------------------------------------------- |
| `SUMX(table, expression)`           | Row-by-row sum                 | `SUMX(Sales, Sales[Quantity]*Sales[UnitPrice]*(1-Sales[Discount]))` |
| `AVERAGEX(table, expression)`       | Row-by-row average             | `AVERAGEX(Sales, Sales[Profit])`                                    |
| `MAXX(table, expression)`           | Maximum value row-by-row       | `MAXX(Sales, Sales[Profit])`                                        |
| `MINX(table, expression)`           | Minimum value row-by-row       | `MINX(Sales, Sales[Profit])`                                        |
| `RANKX(table, expression, , order)` | Ranks rows based on expression | `RANKX(ALL(Sales[Product]), SUM(Sales[SalesAmount]), , DESC)`       |
| `FILTER(table, condition)`          | Returns a filtered table       | `FILTER(Sales, Sales[Profit] > 1000)`                               |

---

## **7.3 Practical Examples**

**Example 1: Rank Products by Sales**

```DAX
Product Sales Rank :=
RANKX(
    ALL(Sales[Product]),
    SUM(Sales[SalesAmount]),
    ,
    DESC
)
```

- Highest-selling product → Rank 1

---

**Example 2: Top 5 Profitable Products**

```DAX
Top 5 Profitable Products :=
CALCULATE(
    SUM(Sales[Profit]),
    FILTER(
        Sales,
        RANKX(ALL(Sales[Product]), SUM(Sales[Profit]), , DESC) <= 5
    )
)
```

- Sums profit for top 5 products only.

---

**Example 3: Category Average Profit (Row-Level)**

```DAX
Avg Profit per Transaction :=
AVERAGEX(
    FILTER(Sales, Sales[Category] = "Electronics"),
    Sales[Profit]
)
```

- Returns average profit **only for Electronics** transactions.

---

**Example 4: Max Profit per Category**

```DAX
Max Profit by Category :=
MAXX(
    FILTER(Sales, Sales[Category] = "Fashion"),
    Sales[Profit]
)
```

- Finds the **single highest profit** in Fashion.

## **7.6 Exercise Answers (For Trainers)**

1. **Rank Products by Profit**

```DAX
Product Profit Rank :=
RANKX(
    ALL(Sales[Product]),
    SUM(Sales[Profit]),
    ,
    DESC
)
```

- Electronics products like Laptops/Phones → Rank 1–3

---

2. **Top 3 Products by Sales**

```DAX
Top 3 Products Sales :=
CALCULATE(
    SUM(Sales[SalesAmount]),
    FILTER(
        Sales,
        RANKX(ALL(Sales[Product]), SUM(Sales[SalesAmount]), , DESC) <= 3
    )
)
```

- Sum includes top 3 high-selling products

---

3. **Average Profit per Electronics Sale**

```DAX
Avg Profit Electronics :=
AVERAGEX(
    FILTER(Sales, Sales[Category] = "Electronics"),
    Sales[Profit]
)
```

- Typically higher than Fashion/Accessories

---

4. **Maximum Profit per Fashion Sale**

```DAX
Max Profit Fashion :=
MAXX(
    FILTER(Sales, Sales[Category] = "Fashion"),
    Sales[Profit]
)
```

- Returns the **highest profit** recorded in Fashion

---

5. **Filter High Value Orders**

```DAX
High Value Sales :=
SUMX(
    FILTER(Sales, Sales[SalesAmount] > 5000),
    Sales[SalesAmount]
)
```

- Sums all sales >5000, usually large Electronics orders
