#### 1. Teacher's Guide Page

**NEXTGEN INNOVATE @ SCHOOL**  
**Emerald Codelines – Teacher Session Plan**

**Duration:** 60-90 minutes  
**Materials Needed:** Computers with Python installed (or online IDE like Replit/Google Colab), projector, printed student notes & exercise sheets.

**Learning Objectives**

- Students will understand why Python is widely used.
- Students will declare variables, use basic data types, and perform simple operations.
- Students will write and run their first Python programs.

**Session Breakdown**

1. **Warm-Up (10 mins):** Discuss: "What programming languages do you know? Why learn Python?" (Used in web dev, data analysis, AI, automation).
2. **Main Teaching (25 mins):**
   - Explain Python syntax, variables (no type declaration), data types (int, float, str, bool).
   - Demo: Print statements, basic operators (+, -, \*, /, //, %).
   - Show input() for user interaction.
3. **Hands-On Activity (30 mins):** Guided coding – Students follow steps to create a simple calculator script.
4. **Wrap-Up (10-15 mins):** Debug common errors, Q&A, assign exercise sheet.

**Teaching Tips**

- Emphasize indentation (use 4 spaces).
- Encourage using comments (#) for explanation.
- Pair programming for support.
- Assessment: Review code from hands-on and exercise sheets.

**Next Session Preview:** Control Structures (If-Else, Loops).

Python is a powerful, easy-to-read language used for web development, data analysis, AI, robotics, and more.

**Why Python?**

- Simple syntax (like English)
- Huge community and libraries
- Versatile for real-world projects

**Key Concepts Today:**

1. **Variables:** Containers to store data. No need to declare type!  
   Example:

   ```python
   name = "Joel"
   age = 15
   height = 1.75
   ```

2. **Data Types:**
   - int (whole numbers: 10)
   - float (decimals: 3.14)
   - str (text: "Hello")
   - bool (True/False)

3. **Basic Operations:**
   - Add, - Subtract, \* Multiply, / Divide, // Floor division, % Modulus

4. **Print and Input:**
   ```python
   print("Hello World!")
   user_name = input("Enter your name: ")
   print("Welcome,", user_name)
   ```

**Step-by-Step: Your First Program**

1. Open Python editor/IDE.
2. Type: print("I am learning Python!")
3. Run it!
